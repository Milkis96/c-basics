배열값을 한 줄로 묶어 이름 하나로

반 친구 30명의 점수를 변수 30개로 만들 수는 없어요. 같은 종류의 값을 기차처럼 한 줄로 이어 붙이고, 이름 하나와 칸 번호로 불러요.

scores

1배열이란?

배열은 같은 종류의 값 여러 개에 이름 하나를 붙인 거예요.각 칸은 번호(인덱스)로 불러요. 번호는 0부터 시작해요.

변수가 "값 하나에 이름 짓기"였다면, 배열은 "값 여러 개를 한 줄로 묶어 이름 짓기"예요. scores[0]은 "scores 기차의 0번 칸"이라는 뜻이에요.

2왜 필요해?

변수로만 하면
int score1 = 90;
int score2 = 75;
int score3 = 88;
// ... score30까지?
배열로 하면
int scores[30];
// 한 줄로 30칸!
// 반복문으로 한 번에 처리

배열의 진짜 힘은 반복문과 함께 쓸 때 나와요. 칸 번호에 변수 i를 넣으면 0번부터 끝까지 차례로 돌 수 있어요.

3쓰는 법

선언

칸 수를 정해서 만들기

int칸마다 담을 종류
scores이름
[4]칸 수
;끝!
선언 + 초기화

만들면서 값 넣기

int scores[4] = {90, 75, 88, 100};
int zeros[5] = {0};          // 모든 칸을 0으로
int nums[] = {1, 2, 3};      // 칸 수를 비우면 값 개수(3)로 정해져요

중괄호 안에 값을 순서대로 쉼표로 나눠 적어요. 값을 덜 적으면 나머지 칸은 0이 돼요.

사용

칸 번호로 꺼내고 바꾸기

printf("%d\n", scores[0]);   // 90 (첫 번째 칸)
scores[1] = 80;                // 1번 칸을 80으로 바꾸기

for (int i = 0; i < 4; i++) {
    printf("%d번: %d\n", i, scores[i]);
}

4칸 번호와 크기

칸 번호는 0부터 시작해요. 4칸짜리 배열의 번호는 0, 1, 2, 3이에요. 마지막 번호는 항상 칸 수 - 1이에요. 4번 칸은 없어요!

몇 번째?첫 번째두 번째세 번째네 번째
칸 번호[0][1][2][3]

배열은 메모리에서 사물함이 빈틈없이 나란히 붙어 있어요. int 배열이면 칸마다 4바이트씩 이어져요. 그래서 번호만 알면 바로 찾아갈 수 있어요.

배열 칸 수를 코드로 알아내기

int scores[4] = {90, 75, 88, 100};
int count = sizeof(scores) / sizeof(scores[0]);   // 16 / 4 = 4

배열 전체 크기(16바이트)를 한 칸 크기(4바이트)로 나누면 칸 수가 나와요.

5기차 따라가기

점수를 하나 바꾸고, 반복문으로 합계를 구해 봐요.

6문제 풀기

1번써 보기

int 5칸짜리 배열 a를 만들고 모든 칸을 0으로 만들어 보세요.

정답 보기
int a[5] = {0};
2번결과 맞히기
int a[4] = {10, 20, 30, 40};
printf("%d", a[2]);
정답 보기

30이에요. 0번이 10, 1번이 20, 2번이 30이에요.

많이 틀리는 답: 20 (번호를 1부터 세서)
3번결과 맞히기
int a[5] = {1, 2};
printf("%d", a[3]);
정답 보기

0이에요. 값을 덜 넣으면 나머지 칸은 0으로 채워져요.

4번틀린 것 찾기
int a[3] = {5, 6, 7};
for (int i = 0; i <= 3; i++) {
    printf("%d ", a[i]);
}
정답 보기

i <= 3 때문에 a[3]까지 읽어요. a[3]은 없는 칸이라 이상한 값이 나와요. i < 3으로 고쳐요.

5번도전

배열 {3, 9, 2, 7}에서 가장 큰 값을 찾아 출력해 보세요.

정답 보기
int a[4] = {3, 9, 2, 7};
int max = a[0];                 // 첫 칸을 일단 최댓값으로
for (int i = 1; i < 4; i++) {
    if (a[i] > max) {
        max = a[i];             // 더 큰 걸 찾으면 바꾸기
    }
}
printf("%d\n", max);            // 9

7이럴 땐?

이상한 값이 나오거나 실행 중에 에러 창이 떠요Run-Time Check Failure #2 - Stack around the variable 'a' was corrupted.
왜?없는 칸 번호를 썼어요. 3칸 배열인데 a[3]에 넣거나 읽었어요. 남의 사물함을 건드린 거예요.
어떻게?번호는 0부터 칸 수 - 1까지. 반복문 조건은 i < 칸 수로 써요.
변수로 배열 크기를 정하니 에러가 나요error C2057: 상수 식이 필요합니다.
왜?Visual Studio에서는 배열 크기를 프로그램 실행 전에 알아야 해요. int n = 5; int a[n];는 안 돼요.
어떻게?숫자를 직접 쓰거나 상수로 정해요.
#define SIZE 5
int a[SIZE];
배열을 통째로 복사하려니 에러가 나요error C2106: '=': 왼쪽 피연산자는 l-value이어야 합니다.
왜?b = a;처럼 배열 전체를 한 번에 넣을 수 없어요.
어떻게?반복문으로 한 칸씩 옮겨요. for (...) b[i] = a[i];
초기화 안 한 배열에 이상한 숫자가 들어 있어요int a[3]; printf("%d", a[0]); → -858993460
왜?변수와 똑같이, 값을 안 넣은 칸에는 쓰레기 값이 있어요.
어떻게?int a[3] = {0};으로 시작해요.

에러 번호와 문구는 Visual Studio 기준이에요. 파일 종류(.c/.cpp)와 버전에 따라 조금 다를 수 있어요.
