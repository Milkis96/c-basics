1Call by reference란?

함수에 변수의 주소를 넘겨서 원본을 바꾸는 방식이에요.reference = 참조, "가리키기". 함수가 원본을 가리켜요.

포인터 시간에 배운 &(주소 알아내기)와 *(주소로 따라가기)를 함수에 쓰는 거예요. 넘기는 쪽은 &a, 받는 쪽은 int *p, 바꿀 때는 *p = ....

정확히 말하면 C는 주소 값을 복사해서 넘겨요(그래서 "Call by address"라고도 해요). 하지만 그 주소로 원본을 바꿀 수 있어서 수업에서는 Call by reference라고 불러요. C++과 C#에는 진짜 참조(&, ref)가 따로 있어요.

2왜 필요해?

여러 값 바꾸기return은 하나만 돌려줘요. swap처럼 둘 이상을 바꾸려면 주소가 필요해요.
이미 써 봤어요scanf_s("%d", &n): scanf_s가 n을 바꿔야 해서 주소를 넘겼던 거예요.
큰 데이터 아끼기큰 구조체를 통째로 복사하지 않고 주소(8바이트)만 넘겨요.

3쓰는 법

3군데만 바꾸기

&로 넘기고, *로 받고, *로 바꾸기

void change(int *p) {    // ② int * 로 주소를 받아요
    *p = 100;            // ③ 주소로 따라가서 원본을 바꿔요
}

int main(void) {
    int a = 5;
    change(&a);          // ① a의 주소를 넘겨요
    printf("%d\n", a);   // 100
    return 0;
}
자리쓰는 것뜻
부르는 곳change(&a)a의 주소를 줄게
매개변수int *pint의 주소를 받을게
함수 안*p = 100그 주소에 가서 100을 넣을게

4value와 비교

Call by value
void swap(int x, int y) {
    int t = x; x = y; y = t;
}
swap(a, b);   // a, b 그대로
값의 복사본을 바꿈 → 원본 그대로
Call by reference
void swap(int *x, int *y) {
    int t = *x; *x = *y; *y = t;
}
swap(&a, &b);   // a, b 바뀜
주소를 따라가서 원본을 바꿈
Call by valueCall by reference
넘기는 것값 (a)주소 (&a)
매개변수int xint *x
원본안 바뀜바뀜
언제값을 읽기만 할 때원본을 바꿔야 할 때, 여러 개를 돌려받을 때

5주소 따라가기

지난 시간에 실패한 swap을 주소로 다시 해 봐요. a는 1000번, b는 1004번에 있다고 할게요.

5번도전

두 수를 받아서 몫과 나머지를 둘 다 돌려주는 함수 divide를 만들어 보세요. (return 하나로는 부족해요)

정답 보기
void divide(int a, int b, int *q, int *r) {
    *q = a / b;
    *r = a % b;
}

int main(void) {
    int q, r;
    divide(17, 5, &q, &r);
    printf("몫 %d, 나머지 %d\n", q, r);   // 몫 3, 나머지 2
    return 0;
}

읽기만 하는 a, b는 값으로, 결과를 받을 q, r은 주소로 넘겨요.

7이럴 땐?

&를 빼먹고 넘겼어요.c: warning C4047: '함수': 'int *'의 간접 참조 수준이 'int'과(와) 다릅니다. · .cpp: error C2664
왜?함수는 주소(int *)를 원하는데 값(int)을 넘겼어요. .c 파일에서는 경고만 나고 실행하면 멈출 수 있어요.
어떻게?change(&a); 경고도 에러라고 생각하고 꼭 고쳐요.
주소를 넘겼는데도 값이 안 바뀌어요p = 100; // * 빠짐
왜?함수 안에서 *를 빼먹어서 쪽지(주소)만 고쳤어요.
어떻게?원본을 바꿀 때는 *p = 100;
*p++ 를 했더니 값이 안 늘어요*p++; // 값 +1이 아니라 주소가 이동
왜?++가 *보다 먼저 붙어서 "p를 옮기기"가 돼요.
어떻게?괄호를 써요. (*p)++; 또는 *p += 1;
실행하자마자 멈춰요예외 발생: 쓰기 액세스 위반입니다. p이(가) 0x5였습니다.
왜?& 없이 값(5)을 넘겨서, 함수가 5번 주소로 가서 쓰려고 했어요. 첫 번째 경고를 무시하면 이렇게 돼요.
어떻게?부르는 곳에 &를 붙여요. 오류 창의 숫자가 원래 넘기려던 값이면 이 경우예요.
