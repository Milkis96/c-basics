Call by value함수에는 복사본이 간다

함수를 부를 때 변수를 넣으면, 변수 자체가 아니라 그 값을 복사한 것이 함수로 가요. 시험지를 복사해서 주면, 복사본에 낙서해도 원본은 깨끗한 것과 같아요.

1Call by value란?

함수에 값을 복사해서 넘기는 방식이에요.value = 값. "값으로 부르기"

함수의 매개변수는 새로 만들어진 변수예요. 함수를 부를 때 넣은 값이 그 새 변수에 복사돼요. 그래서 함수 안에서 매개변수를 아무리 바꿔도 밖의 변수는 그대로예요.

C에서 함수에 무언가를 넘기는 방식은 항상 이거예요. 다음 시간에 배울 Call by reference도 사실은 "주소 값"을 복사해서 넘기는 거예요.

2왜 이렇게 해?

원본 보호함수가 실수로 내 변수를 망가뜨리지 않아요.
함수는 따로 노는 방함수 안의 변수는 함수가 끝나면 사라지는 임시 변수예요. 이름이 같아도 다른 변수예요.
결과는 return으로함수가 계산한 걸 밖으로 보내려면 return을 써요.

3코드로 보기

안 바뀌는 예

함수 안에서 바꿨는데 밖은 그대로

void change(int x) {     // x는 새 변수. a의 값이 복사돼 들어와요
    x = 100;             // 복사본만 바뀌어요
}

int main(void) {
    int a = 5;
    change(a);           // a의 값 5를 복사해서 넘겨요
    printf("%d\n", a);   // 5
    return 0;
}

이름이 같아도 다른 변수예요

void change(int a) {     // 매개변수 이름도 a
    a = 100;             // 함수 안의 a만 바뀌어요
}

main의 a와 change의 a는 사는 방(함수)이 달라요. 이름만 같은 남남이에요.

4그럼 어떻게 바꿔?

방법코드언제
return으로 돌려받기a = twice(a);바꿀 값이 하나일 때
주소 넘기기swap(&a, &b);여러 개를 바꾸거나 원본을 직접 바꿀 때 → Call by reference
int twice(int x) {
    return x * 2;        // 결과를 돌려줘요
}
int main(void) {
    int a = 5;
    a = twice(a);        // 돌려받은 값을 a에 다시 넣어요
    printf("%d\n", a);   // 10
}

6문제 풀기

1번결과 맞히기
void plus(int n) { n = n + 10; }

int main(void) {
    int hp = 50;
    plus(hp);
    printf("%d", hp);
}
정답 보기

50이에요. n은 hp의 복사본이라 n만 60이 됐다가 사라져요.

많이 틀리는 답: 60
2번결과 맞히기
int plus(int n) { n = n + 10; return n; }

int main(void) {
    int hp = 50;
    plus(hp);
    printf("%d", hp);
}
정답 보기

여전히 50이에요. return으로 60을 돌려줬지만 아무도 받지 않았어요. hp = plus(hp);로 받아야 해요.

많이 틀리는 답: 60 (return만 하면 바뀐다고 생각해서)
3번결과 맞히기
void f(int a) { a = 1; printf("%d ", a); }

int main(void) {
    int a = 9;
    f(a);
    printf("%d", a);
}
정답 보기

1 9예요. 함수 안의 a는 1, main의 a는 9. 이름만 같고 다른 변수예요.

4번고쳐 보기
void levelUp(int level) { level++; }

return을 써서 lv가 1 올라가게 고쳐 보세요.

5번도전

위의 swap 함수는 return으로 고칠 수 있을까요? 왜 그럴까요?

정답 보기

어려워요. return은 값을 하나만 돌려줄 수 있는데 swap은 a와 b 둘 다 바꿔야 해요. 그래서 주소를 넘기는 Call by reference가 필요해요.

7이럴 땐?

함수를 불렀는데 값이 안 바뀌어요 (에러는 없음)빌드 성공, 결과만 이상함
왜?Call by value라서 함수가 복사본만 바꿨어요. 이 수업에서 가장 흔한 "에러 없는 버그"예요.
어떻게?디버거로 F11을 눌러 함수 안에 들어가 보세요. 지역 창에 main의 변수가 안 보이고 매개변수만 보여요. return으로 받거나 주소를 넘겨요.
return 했는데도 안 바뀌어요plus(hp); // 돌려받은 값을 버림
왜?return 값을 받는 변수가 없어요.
어떻게?hp = plus(hp);
함수 안에서 main의 변수를 쓰려니 에러가 나요error C2065: 'hp': 선언되지 않은 식별자입니다.
왜?main의 변수는 main 방 안에서만 보여요. 다른 함수는 몰라요.
어떻게?매개변수로 넘겨받아요. void show(int hp)
값을 돌려주는 함수인데 빌드가 안 돼요C4716: 'plus': 값을 반환해야 합니다.
왜?int를 돌려준다고 해 놓고 return을 빼먹었어요.
어떻게?함수 끝에 return 값;을 써요. 돌려줄 게 없으면 void로 바꿔요.
