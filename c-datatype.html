자료형값의 종류 정하기

숫자인지, 소수인지, 글자인지. 변수를 만들 때 값의 종류를 먼저 정해 주면 컴퓨터가 딱 맞는 크기의 상자를 준비해요.

1칸

float

double

한 칸이 1바이트예요. 자료형에 따라 상자 크기가 달라요.

1자료형이란?

자료형은 값의 종류를 정해 주는 거예요.변수가 "값에 이름 짓기"라면, 자료형은 "그 값이 어떤 종류인지 알려 주기"예요.

우리는 3, 3.5, 'A'를 보면 바로 정수, 소수, 글자인 걸 알아요. 하지만 컴퓨터는 미리 말해 주지 않으면 몰라요. 그래서 변수를 만들 때 맨 앞에 종류를 적어 줘요.

int   age    = 12;      // 정수예요
float height = 150.5f;  // 소수예요
char  grade  = 'A';     // 글자 한 개예요

2왜 필요해?

밥은 밥그릇에, 국은 국그릇에 담죠. 그릇이 맞지 않으면 넘치거나 흘러요. 값도 종류에 맞는 상자에 담아야 해요.

맞지 않는 상자
int a = 3.7;
정수 상자에는 소수점 아래가 안 들어가요. 0.7이 흘러 버리고 3만 남아요.
맞는 상자
float a = 3.7f;
소수 상자라서 3.7이 그대로 들어가요.

그리고 컴퓨터는 상자 크기를 아껴 써요. 글자 한 개에는 작은 상자(1칸), 정수에는 그보다 큰 상자(4칸)를 줘요. 종류를 알아야 크기를 정할 수 있어요.

화면에 보여 줄 때도 종류를 알려 줘요

printf에서 %d 같은 기호를 서식 지정자라고 해요. "여기에 이런 종류의 값이 들어간다"는 표시예요. 자료형과 짝을 맞춰야 제대로 보여요.

자료형짝꿍 기호예시화면
int%dprintf("%d", 12);12
float%fprintf("%f", 3.5f);3.500000
double%fprintf("%f", 3.5);3.500000
char%cprintf("%c", 'A');A

%f는 소수점 아래 6자리까지 보여 줘요. %.1f라고 쓰면 한 자리만 보여 줘요. (3.5)

4자료형 네 가지

처음에는 이 네 가지만 알면 충분해요.

char1바이트
글자 한 개등급, 반 이름, 키보드 한 글자
char grade = 'A';
작은따옴표 안에 딱 한 글자만
int4바이트
정수나이, 점수, 사과 개수
int score = 90;
약 -21억부터 21억까지 담을 수 있어요
float4바이트
소수키, 몸무게, 캐릭터 속도
float speed = 2.5f;
소수점 아래 6~7자리 정도까지 정확해요
double8바이트
더 정확한 소수원주율, 과학 계산
double pi = 3.141592;
float보다 두 배 커서 15자리 정도까지 정확해요

어떤 걸 고를까? 개수나 점수처럼 딱 떨어지면 int, 소수점이 필요하면 float, 글자 한 개면 char예요. double은 아주 정확한 계산이 필요할 때 써요.

알아 두면 재밌는 비밀: char는 사실 숫자예요

컴퓨터는 글자를 번호로 기억해요. 'A'는 65번, 'B'는 66번이에요. 이 번호표를 아스키 코드라고 해요.

char c = 'A';
printf("%c", c);   // A  (글자로 보여 줘)
printf("%d", c);   // 65 (번호로 보여 줘)

그래서 char 상자에 숫자 넣기, int 상자에 글자 넣기가 가능해요. 아래 실험실에서 직접 해 보세요.

6문제 풀기

먼저 스스로 풀어 보고 정답을 열어 보세요. 3번부터는 머릿속으로 결과를 맞혀 보세요.

1번써 보기

키 152.3을 담는 변수 height를 만들어 보세요.

정답 보기
float height = 152.3f;

소수라서 float예요. double height = 152.3;도 정답이에요.

2번골라 보기

각각 어떤 자료형이 알맞을까요?

  • 우리 반 학생 수
  • 몸무게 41.5kg
  • 혈액형 A형의 'A'
  • 게임 점수
정답 보기

학생 수 int, 몸무게 float, 혈액형 char, 게임 점수 int예요. 사람 수처럼 반으로 나눌 수 없는 건 정수예요.

3번결과 맞히기
char c = 'B';
printf("%d", c);
정답 보기

66이에요. %d는 숫자로 보여 달라는 뜻이라 'B'의 번호인 66이 나와요. 'A'가 65니까 'B'는 66이에요.

많이 틀리는 답: B (%d와 %c를 헷갈려서)
4번틀린 것 찾기

잘못 쓴 것을 모두 골라 보세요.

char a = 'A';
char b = "B";
char c = 'CD';
int  d = 10;
float e = 2.5f;
정답 보기

b와 c예요. 글자 한 개는 작은따옴표로 감싸고('B'), 안에는 딱 한 글자만 넣어야 해요. 큰따옴표 "B"는 글자 여러 개를 담는 문자열이라 다른 거예요. 문자열은 3주차에 배워요.

5번도전
float a = 7 / 2;
printf("%f", a);
정답 보기

3.000000이에요. float 상자인데 왜 3.5가 아닐까요? 7과 2가 둘 다 정수라서 컴퓨터가 정수끼리 먼저 나눠요. 정수 나눗셈은 몫만 남기니까 3이 되고, 그 3을 float 상자에 넣어서 3.0이 돼요.

3.5를 얻으려면 둘 중 하나를 소수로 써요.

float a = 7.0f / 2;   // 3.500000
많이 틀리는 답: 3.500000 (상자가 float이면 계산도 소수로 할 거라고 생각해서)

7이럴 땐?

자료형 때문에 자주 생기는 일이에요. 화면에 뜬 모습과 비슷한 걸 찾아보세요.

0.000000이나 이상한 숫자가 나와요warning C4477: 'printf' : 서식 문자열 '%d'에 'int' 형식의 인수가 필요하지만 ... 'double'입니다.
왜?자료형과 서식 지정자 짝이 안 맞아요. float 값을 %d로, int 값을 %f로 보여 달라고 했어요.
어떻게?int는 %d, float·double은 %f, char는 %c로 짝을 맞춰요.
float s = 2.5f;
printf("%d", s);   // 틀림: 이상한 숫자
printf("%f", s);   // 맞음: 2.500000
나눗셈 결과에서 소수점이 사라져요7 / 2 → 3
왜?정수끼리 나누면 몫만 남아요. 결과를 float 상자에 넣어도 이미 3이 된 뒤예요.
어떻게?둘 중 하나를 소수로 써요. 7.0f / 2
float에 소수를 넣었더니 경고가 나요warning C4305: '초기화 중': 'double'에서 'float'(으)로 잘립니다.
왜?소수 뒤에 f가 없으면 컴퓨터는 double(8칸)로 생각해요. 그걸 float(4칸)에 넣으니 "잘릴 수도 있다"고 알려 주는 거예요.
어떻게?float에 넣는 소수 뒤에는 f를 붙여요. float h = 152.3f;
숫자를 더했는데 갑자기 음수가 돼요2147483647 + 1 → -2147483648
왜?int 상자에는 약 21억까지만 들어가요. 넘치면 숫자가 한 바퀴 돌아서 가장 작은 음수가 돼요. 이걸 오버플로라고 해요.
어떻게?아주 큰 수가 필요하면 더 큰 상자인 long long(8바이트)을 써요.
char에 글자를 넣었는데 경고가 나거나 엉뚱한 글자가 나와요char b = "B"; · char c = 'CD';
왜?큰따옴표는 문자열이라 char 상자에 안 맞아요. 작은따옴표 안에 두 글자를 넣어도 한 글자만 남아요.
어떻게?char에는 작은따옴표 안에 한 글자만. char b = 'B';
