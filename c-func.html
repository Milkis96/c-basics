함수자주 하는 일에 이름 붙여 두기

값을 넣으면 정해진 일을 하고 결과를 돌려주는 작은 기계예요. 한 번 만들어 두면 이름만 불러서 몇 번이고 쓸 수 있어요.

1함수란?

함수는 자주 하는 일에 이름을 붙여 둔 거예요.변수가 값에 이름 짓기라면, 함수는 할 일(코드 묶음)에 이름 짓기예요.

우리는 이미 함수를 써 왔어요. printf, scanf_s도 누군가 만들어 둔 함수예요. 그리고 프로그램이 시작되는 main도 함수예요. 이제 우리만의 함수를 만들어 볼게요.

2왜 필요해?

같은 코드를 또 안 써도 돼요공격 계산을 10곳에서 한다면, 함수 하나를 10번 부르면 끝이에요.
고칠 때 한 곳만 고쳐요공격 공식이 바뀌면 함수 안만 고치면 돼요.
코드가 읽기 쉬워져요attack(), heal()처럼 이름만 봐도 무슨 일을 하는지 알아요.

3쓰는 법

만들기 (정의)

기계 설계하기

int돌려줄 값의 종류
add함수 이름
(int a, int b)받을 재료
int add(int a, int b) {
    int result = a + b;
    return result;      // 결과를 돌려줘요
}
부르기 (호출)

기계 사용하기

int main(void) {
    int x = add(3, 4);          // 3, 4를 넣고 결과 7을 x에 받기
    printf("%d\n", x);          // 7
    printf("%d\n", add(10, 5)); // 15 (바로 출력도 돼요)
    return 0;
}

함수 이름 뒤 괄호에 재료를 넣어 부르면, 함수 안 코드가 실행되고 return 값이 그 자리로 돌아와요.

void

돌려줄 게 없을 때

void hello(void) {
    printf("안녕하세요!\n");
}
// 부르기: hello();

결과를 돌려주지 않고 일만 하는 함수는 void(비어 있음)를 써요. 재료가 없을 때도 괄호 안에 void를 써요.

4함수의 부품

부품뜻add에서는
반환형돌려줄 값의 종류int
함수 이름부를 때 쓰는 이름add
매개변수재료를 받는 변수 (함수 쪽)int a, int b
인자부를 때 실제로 넣는 값3, 4
return결과를 돌려주고 함수 끝내기return result;

함수 안 변수는 함수 안에서만 살아요

함수 안에서 만든 변수(result)와 매개변수(a, b)는 지역 변수예요. 함수가 끝나면 사라져요. 메모리 시간에 본 스택(교실) 정리예요.

main보다 아래에 만들 때는 미리 알려 줘요

int add(int a, int b);   // 선언: "이런 함수가 있어요" (세미콜론!)

int main(void) {
    printf("%d\n", add(3, 4));
    return 0;
}

int add(int a, int b) {  // 정의: 실제 내용
    return a + b;
}

컴퓨터는 위에서 아래로 읽어요. main에서 add를 부를 때 아직 add를 못 봤다면, 위에 선언을 한 줄 적어 두어요.

5함수 따라가기

add를 부르면 실행 위치가 함수 안으로 갔다가 돌아와요. a와 b가 생겼다 사라지는 것도 보세요.

void star(void) {

3번결과 맞히기
int twice(int x) {
    x = x * 2;
    return x;
}
int main(void) {
    int a = 5;
    twice(a);
    printf("%d", a);
    return 0;
}
정답 보기

5예요. 함수에는 a의 값만 복사되어 x에 들어가요. x를 바꿔도 a는 그대로예요. 그리고 돌려준 10은 아무도 받지 않았어요. 받으려면 a = twice(a);라고 써요.

많이 틀리는 답: 10. 이게 2개월차 Call by value예요.
4번틀린 것 찾기
int add(int a, int b) {

7이럴 땐?

함수를 찾을 수 없다고 나와요.cpp: error C3861: 'add': 식별자를 찾을 수 없습니다. · .c: warning C4013: 'add'이(가) 정의되지 않았습니다.
왜?함수를 main 아래에 만들고 위에 선언을 안 했어요. 또는 이름 철자가 달라요.
어떻게?main 위로 옮기거나, 위에 선언 한 줄 int add(int a, int b);를 넣어요.
인자 개수가 안 맞는다고 나와요error C2660: 'add': 함수는 1개의 인수를 사용하지 않습니다.
왜?재료 2개가 필요한 함수에 1개만 넣었어요. add(3)
어떻게?함수의 매개변수 개수와 순서에 맞게 넣어요. add(3, 4)
값을 돌려주지 않는다는 경고가 나요warning C4716: 'add': 값을 반환해야 합니다.
왜?반환형이 int인데 return이 없어요.
어떻게?돌려줄 값을 return으로 보내요. 돌려줄 게 없으면 반환형을 void로 바꿔요.
함수 안에서 바꿨는데 밖의 변수가 그대로예요twice(a); → a는 그대로
왜?함수에는 값의 복사본이 가요. 원본은 안 바뀌어요.
어떻게?돌려받아서 넣어요. a = twice(a); 원본을 직접 바꾸는 방법은 포인터에서 배워요.
