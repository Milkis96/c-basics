1조건문이란?

조건문은 "만약 ~라면"을 코드로 쓰는 거예요.조건이 맞으면(참) 이 길로, 틀리면(거짓) 저 길로 가요.

C언어에서 참은 1(0이 아닌 수), 거짓은 0이에요. 5 > 3을 계산하면 1, 5 < 3을 계산하면 0이 나와요.

2왜 필요해?

조건문이 없으면 프로그램은 항상 똑같은 일만 해요. 게임은 상황마다 다르게 움직여야 하죠.

체력이 0 이하면게임 오버
점수가 90점 이상이면A등급
가위바위보에서이겼는지, 졌는지, 비겼는지

3쓰는 법

if

만약 ~라면

if (hp <= 0) {
    printf("게임 오버\n");
}

괄호 안 조건이 참이면 중괄호 { } 안을 실행해요. 거짓이면 건너뛰어요.

if - else

아니면

if (hp <= 0) {
    printf("게임 오버\n");
} else {
    printf("계속 싸워요\n");
}

조건이 거짓일 때 갈 길을 else로 정해요. 둘 중 딱 하나만 실행돼요.

else if

갈림길이 여러 개일 때

if (score >= 90) {
    printf("A\n");
} else if (score >= 80) {
    printf("B\n");
} else {
    printf("C\n");
}

위에서부터 차례로 확인하다가 처음 맞는 곳 하나만 실행하고 끝내요. 85점이면 첫 조건은 거짓, 두 번째가 참이라 B가 나와요.

switch

값이 딱 정해져 있을 때

switch (menu) {
case 1:
    printf("시작\n");
    break;
case 2:
    printf("설정\n");
    break;
default:
    printf("잘못 눌렀어요\n");
    break;
}

menu 값과 같은 case로 바로 가요. break를 만나면 switch를 빠져나가요. 맞는 게 없으면 default로 가요.

4비교와 논리

비교 연산자: 크다, 작다, 같다

기호뜻예시 (a = 5)결과
>크다a > 3참 (1)
<작다a < 3거짓 (0)
>=크거나 같다 (이상)a >= 5참 (1)
<=작거나 같다 (이하)a <= 4거짓 (0)
==같다 (= 두 개!)a == 5참 (1)
!=같지 않다a != 5거짓 (0)

= 하나는 "넣어라", == 두 개는 "같니?"예요. 가장 많이 헷갈리는 부분이에요.

논리 연산자: 그리고, 또는, 아니다

기호뜻예시언제 참?
&&그리고age >= 8 && age <= 13둘 다 참일 때
||또는key == 'q' || key == 'Q'하나라도 참일 때

6문제 풀기

1번결과 맞히기
int a = 5;
if (a > 3) printf("A");
else printf("B");
정답 보기

A예요. 5 > 3은 참이에요.

2번결과 맞히기
int score = 70;
if (score >= 90) printf("A");
else if (score >= 80) printf("B");
else if (score >= 70) printf("C");
else printf("D");
정답 보기

C예요. 70 >= 70은 참이에요. "이상"은 같은 것도 포함해요.

많이 틀리는 답: D (>=를 >로 착각)
3번틀린 것 찾기
int a = 3;
if (a = 5) {
    printf("a는 5예요");
}
정답 보기

a = 5는 "a에 5를 넣어라"예요. 5가 들어가고 결과도 5(참)라서 항상 출력돼요. 비교하려면 a == 5라고 써요.

4번결과 맞히기
int menu = 1;
switch (menu) {
case 1: printf("시작 ");
case 2: printf("설정 ");
    break;
case 3: printf("종료 ");
}
정답 보기

시작 설정이에요. case 1에 break가 없어서 case 2까지 흘러 내려가요. break를 만나서야 멈춰요.

7이럴 땐?

조건이 틀려도 항상 실행돼요if (a = 5)
왜?==가 아니라 =를 썼어요. 비교가 아니라 넣기가 돼요.
어떻게?비교는 ==. 실수 방지로 if (5 == a)처럼 값을 왼쪽에 쓰는 방법도 있어요.
if 안의 코드가 조건과 상관없이 실행돼요if (hp <= 0);
왜?if 괄호 뒤에 세미콜론을 붙였어요. "조건이 맞으면 아무것도 안 하기"로 끝나 버리고, 아래 중괄호는 그냥 실행돼요.
어떻게?if ( ) 뒤에는 세미콜론을 붙이지 않아요.
두 번째 줄은 조건과 상관없이 실행돼요if (win) printf("승리\n"); printf("보상 받기\n");
왜?중괄호가 없으면 if는 바로 다음 한 줄만 책임져요.
어떻게?한 줄이어도 중괄호 { }를 쓰는 습관을 들여요.
범위 조건이 이상하게 동작해요if (0 < a < 10)
왜?C는 0 < a를 먼저 계산해서 0이나 1을 만들고, 그걸 10과 비교해요. 그래서 항상 참이에요.
어떻게?두 조건으로 나눠서 &&로 이어요. if (0 < a && a < 10)
switch에서 다른 case까지 같이 실행돼요case 1: ... (break 없음)
왜?break가 없으면 아래 case로 계속 내려가요.
어떻게?case마다 끝에 break;를 넣어요.
