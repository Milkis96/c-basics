입/출력컴퓨터와 말 주고받기

출력은 컴퓨터가 화면에 말하는 것, 입력은 우리가 키보드로 컴퓨터에게 말하는 거예요. printf로 말하고 scanf_s로 들어요.

printf나이를 입력하세요:
scanf_s12
printf내년에는 13살!
1입출력이란?2왜 필요해?3쓰는 법4짝꿍 기호5대화 따라가기6문제 풀기7이럴 땐?8다음에 배울 것

1입출력이란?

출력은 보여 주기, 입력은 받아 오기예요.printf는 컴퓨터의 입, scanf_s는 컴퓨터의 귀라고 생각하세요.

출력(printf): 컴퓨터가 글자나 값을 화면에 보여 줘요.
입력(scanf_s): 우리가 키보드로 친 값을 변수에 넣어 줘요.

둘 다 쓰려면 프로그램 맨 위에 #include <stdio.h>를 적어요. "입출력 도구 상자를 가져와"라는 뜻이에요.

2왜 필요해?

입력이 없으면
int age = 12;
나이가 바뀔 때마다 코드를 고치고 다시 실행해야 해요.
입력이 있으면
scanf_s("%d", &age);
실행할 때마다 다른 나이를 넣을 수 있어요. 게임에서 이름이나 메뉴를 고르는 것도 입력이에요.

3쓰는 법

출력

printf: 보여 주기

printf("안녕하세요\n");          // 글자 그대로
printf("점수: %d\n", score);     // %d 자리에 score 값이 들어가요
printf("%d + %d = %d\n", a, b, a + b);  // 여러 개도 순서대로

큰따옴표 안의 글자가 그대로 나오고, %d 같은 자리에 뒤쪽 값이 순서대로 들어가요. \n은 줄을 바꾸는 표시예요.

입력

scanf_s: 받아 오기

scanf_s입력받아라
("%d",정수로
&ageage의 집으로
);끝!

&를 꼭 붙여요. &age는 "age 변수가 사는 집 주소"라는 뜻이에요. scanf_s는 주소를 알아야 그 집에 값을 넣어 줄 수 있어요. (주소는 메모리, 포인터 시간에 자세히 배워요.)

주의

글자(char)를 받을 때는 크기도 알려 줘요

char grade;
scanf_s(" %c", &grade, 1);   // 마지막 1 = 상자 크기 1칸

scanf_s는 안전한 입력 도구라서, 글자를 받을 때 "상자가 몇 칸인지"를 같이 알려 줘야 해요. %c 앞의 빈칸은 7번 "이럴 땐?"에서 설명해요.

4짝꿍 기호

자료형마다 짝꿍 기호가 있어요. 입력과 출력에서 조금 다른 것도 있으니 표로 기억해요.

자료형printfscanf_s입력 예시
int%d%dscanf_s("%d", &n);
float%f%fscanf_s("%f", &h);
double%f%lfscanf_s("%lf", &d);
char%c%c + 크기scanf_s(" %c", &c, 1);

보기 좋게 출력하기

쓰는 법뜻예시화면
%.2f소수점 아래 2자리까지printf("%.2f", 3.14159);3.14
%5d5칸 자리 잡고 오른쪽 정렬printf("[%5d]", 42);[ 42]
\n줄 바꾸기printf("A\nB");A 다음 줄에 B
\t탭 (넓은 띄어쓰기)printf("A\tB");A      B
%%% 글자 자체printf("100%%");100%

5대화 따라가기

한 줄씩 실행해 보세요. 3번 줄에서 프로그램이 멈추고 우리가 12를 입력한다고 해 볼게요.

6문제 풀기

1번써 보기

정수 변수 score에 키보드로 값을 입력받는 줄을 써 보세요.

정답 보기
scanf_s("%d", &score);

&를 빼먹지 않았나요?

2번결과 맞히기
int a = 3, b = 4;
printf("%d + %d = %d\n", a, b, a + b);
정답 보기

3 + 4 = 7이에요. %d 세 자리에 a, b, a + b가 순서대로 들어가요.

3번결과 맞히기
printf("%.1f", 2.75);
정답 보기

2.8이에요. 소수점 아래 한 자리까지 보여 주면서 반올림해요. (출력할 때만 반올림이고, 값 자체는 그대로예요.)

4번틀린 것 찾기

잘못 쓴 줄을 모두 골라 보세요.

int n;  char c;  double d;
scanf_s("%d", n);
scanf_s(" %c", &c);
scanf_s("%lf", &d);
printf("%d\n", n);
정답 보기

2번째 줄은 &가 빠졌어요. &n이어야 해요.
3번째 줄은 글자 크기가 빠졌어요. scanf_s(" %c", &c, 1);이어야 해요.

5번도전

정수 두 개를 입력받아서 합을 출력하는 프로그램을 써 보세요.

정답 보기
#include <stdio.h>

int main(void) {
    int a, b;
    printf("두 수를 입력하세요: ");
    scanf_s("%d %d", &a, &b);   // 띄어쓰기나 Enter로 구분해서 입력
    printf("합: %d\n", a + b);
    return 0;
}

7이럴 땐?

scanf를 썼더니 "안전하지 않다"는 에러가 나요error C4996: 'scanf': This function or variable may be unsafe. Consider using scanf_s instead.
왜?Visual Studio는 scanf 대신 더 안전한 scanf_s를 쓰라고 막아요.
어떻게?우리 수업에서는 scanf_s를 써요. char와 문자열은 크기를 함께 넘겨요.
입력하자마자 프로그램이 멈추거나 값이 안 들어가요warning C4477: 'scanf_s' : 서식 문자열 '%d'에 'int *' 형식의 인수가 필요하지만 ... 'int'입니다.
왜?변수 앞에 &를 빼먹었어요. 주소를 모르니 값을 넣을 곳을 못 찾아요.
어떻게?scanf_s("%d", &age);처럼 &를 붙여요.
숫자 입력 다음에 글자 입력이 그냥 넘어가요scanf_s("%d", &n); scanf_s("%c", &c, 1); → c에 Enter가 들어감
왜?숫자를 치고 누른 Enter(\n)가 남아 있다가 %c에 들어가 버려요.
어떻게?%c 앞에 빈칸을 하나 넣어요. 빈칸은 "남은 Enter나 띄어쓰기는 건너뛰어"라는 뜻이에요.
scanf_s(" %c", &c, 1);
double로 입력받았더니 값이 이상해요scanf_s("%f", &d); // d는 double
왜?scanf_s에서 double의 짝꿍은 %f가 아니라 %lf예요.
어떻게?scanf_s("%lf", &d); 출력할 때는 %f로 괜찮아요.
char 입력에서 인수가 부족하다는 경고가 나요warning C4473: 'scanf_s' : 형식 문자열에 전달된 인수가 부족합니다.
왜?%c를 쓰면서 크기를 안 알려 줬어요.
어떻게?맨 뒤에 크기 1을 넣어요.

에러 번호와 문구는 Visual Studio 기준이에요. 파일 종류(.c/.cpp)와 버전에 따라 조금 다를 수 있어요.
