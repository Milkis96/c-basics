반복문같은 일 여러 번 시키기

"운동장 10바퀴 돌아!"처럼 같은 일을 정해진 만큼, 또는 조건이 맞는 동안 계속 시키는 방법이에요.

1반복문이란?

반복문은 같은 코드를 여러 번 실행하게 해요.조건이 참인 동안 계속 돌고, 거짓이 되면 멈춰요.

반복할 때마다 숫자를 세는 변수를 많이 써요. 보통 이름을 i라고 지어요. "몇 바퀴째인지" 기억하는 변수예요.

2왜 필요해?

반복문 없이
printf("1\n");
printf("2\n");
printf("3\n");
// ... 100까지 100줄?!
반복문으로
for (int i = 1; i <= 100; i++) {
    printf("%d\n", i);
}
// 3줄이면 끝

게임은 사실 커다란 반복문이에요. 화면 그리기, 입력 확인, 움직이기를 1초에 수십 번 반복해요.

3쓰는 법

가장 많이 쓰는 for문은 괄호 안에 세 칸이 있어요.

for (
int i = 1;① 시작
i <= 5;② 계속할 조건
i++④ 한 바퀴 뒤에
)
for (int i = 1; i <= 5; i++) {
    printf("%d바퀴\n", i);   // ③ 반복할 일
}

순서는 ① 시작 → ② 조건 확인 → ③ 반복할 일 → ④ i 올리기 → ② 조건 확인 → ...이에요. ②가 거짓이 되는 순간 반복을 끝내요.

4세 가지 반복문

for몇 번 돌지 알 때
for (int i = 0; i < 3; i++) {
    printf("*");
}
"10바퀴 돌아"
while언제 끝날지 모를 때
while (hp > 0) {
    hp -= 10;
}
"체력이 남아 있는 동안 싸워"
do while일단 한 번은 할 때
do {
    scanf_s("%d", &n);
} while (n < 0);
"일단 입력받고, 틀리면 다시"

while은 조건을 먼저 확인하고, do while은 나중에 확인해요. 그래서 do while은 조건이 처음부터 거짓이어도 한 번은 실행돼요. 끝에 세미콜론 ;을 붙이는 것도 잊지 마세요.

반복을 멈추거나 건너뛰기

명령뜻예시
break;반복문을 바로 빠져나가요정답을 맞히면 그만 묻기
continue;이번 바퀴만 건너뛰고 다음 바퀴로짝수만 출력하고 홀수는 건너뛰기

5바퀴 세기

1부터 3까지 더하는 반복문이에요. i가 어떻게 바뀌고, 언제 멈추는지 따라가 보세요.

6문제 풀기

1번결과 맞히기
for (int i = 0; i < 3; i++) {
    printf("*");
}
정답 보기

***이에요. i가 0, 1, 2일 때 세 번 돌아요. 3이 되면 3 < 3이 거짓이라 멈춰요.

많이 틀리는 답: **** (0부터 3까지 네 번이라고 생각해서)
2번결과 맞히기
for (int i = 1; i <= 10; i += 3) {
    printf("%d ", i);
}
정답 보기

1 4 7 10이에요. 3씩 올라가요. 13은 10보다 커서 멈춰요.

3번틀린 것 찾기
int i = 0;
while (i < 5) {
    printf("%d\n", i);
}
정답 보기

i가 계속 0이라서 영원히 멈추지 않아요(무한 반복). 안에 i++;를 넣어야 해요.

4번결과 맞히기
int n = 10;
do {
    printf("안녕 ");
} while (n < 5);
정답 보기

안녕이 한 번 나와요. do while은 일단 한 번 실행한 뒤에 조건을 확인해요.

많이 틀리는 답: 아무것도 안 나온다 (while처럼 먼저 확인한다고 생각해서)
5번도전

1부터 10까지의 합을 구해서 출력해 보세요.

정답 보기
int sum = 0;
for (int i = 1; i <= 10; i++) {
    sum += i;
}
printf("%d\n", sum);   // 55

sum을 0으로 초기화하는 걸 잊지 마세요.

7이럴 땐?

프로그램이 끝나지 않고 계속 돌아요무한 반복 (화면이 계속 올라가거나 멈춘 것처럼 보여요)
왜?조건이 영원히 거짓이 되지 않아요. i를 안 올렸거나, 방향을 반대로 바꿨어요.
어떻게?콘솔 창에서 Ctrl + C로 멈춰요. 그리고 반복할 때마다 조건 속 변수가 끝을 향해 바뀌는지 확인해요.
한 번 더, 또는 한 번 덜 돌아요for (int i = 0; i <= 5; i++) → 6번
왜?시작 값과 < / <= 를 헷갈렸어요.
어떻게?"0부터 시작하면 < 개수", "1부터 시작하면 <= 개수"로 기억해요. 헷갈리면 i가 마지막에 몇인지 손으로 세어 봐요.
반복문 안의 코드가 한 번만 실행돼요for (int i = 0; i < 5; i++);
왜?for 괄호 뒤에 세미콜론을 붙였어요. "아무것도 안 하기"를 5번 하고, 아래 중괄호는 한 번만 실행돼요.
어떻게?for ( ) 뒤의 세미콜론을 지워요.
반복문이 끝난 뒤 i를 쓰니 에러가 나요error C2065: 'i': 선언되지 않은 식별자입니다.
왜?for (int i = ...)에서 만든 i는 반복문 안에서만 살아 있어요.
어떻게?밖에서도 쓰려면 반복문 위에서 int i;를 먼저 만들어요.
