1동적 할당이란?

실행 중에 메모리를 빌리고(new) 반납하는(delete) 것이에요.동적 = 실행하면서 정해진다. 할당 = 나눠 준다.
실행 중에 메모리를 빌리고(malloc) 반납하는(free) 것이에요.동적 = 실행하면서 정해진다. 할당 = 나눠 준다.

도서관에서 책을 빌리는 것과 같아요. 빌리면 대출 번호(주소)를 받고, 그 번호로 책을 찾아 써요. 다 읽으면 반납해야 다른 사람이 빌릴 수 있어요. 반납을 안 하면 도서관 책이 점점 줄어들어요.

  • new: 자료형과 칸 수를 말하면 그만큼 빌려 주고, 시작 주소를 돌려줘요.
  • delete: 빌린 주소를 주면 반납해요. 배열로 빌렸으면 delete[].
  • 빌린 메모리에는 이름이 없어요. 그래서 포인터로 주소를 들고 있어야 해요.
  • malloc: 바이트 수를 말하면 그만큼 빌려 주고, 시작 주소를 돌려줘요.
  • free: 빌린 주소를 주면 반납해요.
  • 빌린 메모리에는 이름이 없어요. 그래서 포인터로 주소를 들고 있어야 해요.

new는 C++ 문법이에요

Visual Studio에서 파일 이름이 .cpp여야 해요. .c 파일에서는 new를 몰라요. printf, scanf_s, 포인터는 .cpp에서도 그대로 써요.

2왜 필요해?

보통 배열

int score[30]; 학생이 몇 명 올지 모르니 넉넉하게 잡아요. 5명이면 25칸이 낭비, 31명이면 모자라요.

동적 할당

학생 수를 먼저 입력받고, 딱 그만큼만 빌려요. 낭비도 없고 모자라지도 않아요.

크기를 실행 중에 정하기입력받은 숫자만큼 배열을 만들 수 있어요.
함수가 끝나도 남기기함수 안의 변수는 함수가 끝나면 사라지지만, 빌린 메모리는 반납 전까지 남아요.
게임 오브젝트총알, 적처럼 실행 중에 생기고 사라지는 것들. 유니티에서도 같은 생각을 써요.

기본 순서

빌리기 → 쓰기 → 반납

int n;
scanf_s("%d", &n);

int *arr = new int[n];          // ① int n칸 빌리기
for (int i = 0; i < n; i++) {
    arr[i] = 0;                 // ② 배열처럼 쓰기
}
delete[] arr;                   // ③ 반납 (배열이니까 [ ])
arr = nullptr;                  //    반납한 주소 지우기
빌리기반납뜻
new intdelete p;int 1칸
new int(5)delete p;int 1칸, 값 5로 시작
new int[5]delete[] p;int 5칸 (안은 쓰레기 값)
new int[5]()delete[] p;int 5칸, 모두 0
  • 짝을 맞춰요. new ↔ delete, new[] ↔ delete[].
  • malloc과 달리 sizeof도, (int *)도 필요 없어요. 자료형을 보고 알아서 크기를 계산해요.
  • new int(5)와 new int[5]는 완전히 달라요. 괄호 모양을 잘 보세요.

C#에서는

int n = 3;
int[] arr = new int[n];   // * 없이 배열 자료형. 안은 모두 0
arr[2] = 30;
// delete 없음! 아무도 arr을 안 쓰면 가비지 컬렉터가 알아서 반납

C#도 new로 빌리는 건 같아요. 대신 반납은 가비지 컬렉터가 대신해 줘서 delete를 쓰지 않아요.

빌리기

malloc 한 줄 뜯어보기

int *arr주소를 받을 포인터
=넣어라
(int *)int 주소로 쓸게요
malloc(sizeof(int) * n)int n개 크기만큼 빌려 줘
;끝!
기본 순서

빌리기 → 확인 → 쓰기 → 반납

#include <stdlib.h>                         // malloc, free가 여기 있어요

int n;
scanf_s("%d", &n);

int *arr = (int *)malloc(sizeof(int) * n);   // ① 빌리기
if (arr == NULL) {                           // ② 못 빌렸는지 확인
    printf("메모리 부족\n");
    return 1;
}
for (int i = 0; i < n; i++) {
    arr[i] = 0;                              // ③ 배열처럼 쓰기
}
free(arr);                                   // ④ 반납
arr = NULL;                                  //    반납한 주소 지우기
함수하는 일예시
malloc빌리기. 안은 쓰레기 값malloc(sizeof(int) * 5)
calloc빌리고 모두 0으로 채우기calloc(5, sizeof(int))
realloc빌린 크기 바꾸기realloc(arr, sizeof(int) * 10)
free반납free(arr)
  • sizeof를 꼭 곱해요. malloc은 칸 수가 아니라 바이트 수를 받아요. malloc(n)은 n바이트, int로는 n/4칸뿐이에요.
  • (int *)는 .cpp 파일에서 필요해요. 붙여 두면 .c, .cpp 둘 다 돼요.
  • free는 malloc 하나에 한 번. 배열이든 하나든 똑같이 free(주소)예요.

4스택과 힙

메모리에는 변수가 사는 동네가 두 곳 있어요.

규칙 하나: 빌린 방식으로 한 번 반납

new는 delete로, new[]는 delete[]로, 딱 한 번. malloc으로 빌린 걸 delete 하거나 new로 빌린 걸 free 하면 안 돼요. 덜 반납하면 메모리 누수, 두 번 반납하면 프로그램이 멈춰요.

malloc 한 번에 free 한 번. new로 빌린 걸 free 하거나 malloc으로 빌린 걸 delete 하면 안 돼요. 덜 반납하면 메모리 누수, 두 번 반납하면 프로그램이 멈춰요.

5번도전

학생 수 n을 입력받고, new로 n칸 배열을 만들어 점수를 입력받은 뒤 평균을 출력하세요. 마지막에 반납까지 해요. (.cpp 파일)

정답 보기
#include <stdio.h>

int main() {
    int n, sum = 0;
    printf("학생 수: ");
    scanf_s("%d", &n);

    int *score = new int[n];

    for (int i = 0; i < n; i++) {
        printf("%d번 점수: ", i + 1);
        scanf_s("%d", &score[i]);
        sum += score[i];
    }
    printf("평균: %.1f\n", (double)sum / n);

    delete[] score;
    score = nullptr;
    return 0;
}

7이럴 땐?

new를 모른다고 나와요error C2065: 'new': 선언되지 않은 식별자입니다.
왜?파일이 .c예요. new는 C++ 문법이라 C 파일에서는 몰라요.
어떻게?파일을 .cpp로 만들어요. C 방식으로 하려면 위의 "malloc / free" 버튼을 눌러 보세요.
delete 줄에 초록 물결 경고가 생겨요C6278: 'arr'이(가) 배열 new []로 할당되었지만 스칼라 delete로 삭제되었습니다.
왜?new int[n]으로 빌리고 delete arr;로 반납했어요. int 배열은 당장 멀쩡해 보일 수 있지만 규칙 위반이고, 나중에 클래스 배열에서는 프로그램이 멈춰요.
어떻게?delete[] arr; 빌릴 때 [ ]가 있었으면 반납할 때도 [ ].
delete 할 때 프로그램이 멈추며 창이 떠요HEAP CORRUPTION DETECTED: after Normal block ... CRT detected that the application wrote to memory after end of heap buffer.
왜?빌린 칸보다 많이 썼어요. 반복 조건이 i <= n이거나, new int(n)으로 1칸만 빌려 놓고 n칸을 썼을 때예요.
어떻게?빌린 줄이 new int[n]인지(괄호 모양), 반복 조건이 i < n인지 확인해요.
delete를 했는데 또 멈춰요Debug Assertion Failed! Expression: _CrtIsValidHeapPointer(block)
왜?같은 주소를 두 번 delete 했거나, new로 빌리지 않은 주소(보통 배열, 변수 주소)를 delete 했어요.
어떻게?delete 후에 p = nullptr;을 넣어요. delete nullptr은 아무 일도 안 해서 안전해요.
반납한 뒤에 읽었더니 이상한 큰 음수가 나와요-572662307 (0xDDDDDDDD)
왜?Debug 모드에서 반납된 칸은 0xDD로 채워져요. 반납한 메모리를 읽었다는 신호예요.
어떻게?delete는 그 메모리를 다 쓴 다음, 맨 마지막에 해요.
(C#) 실행 중에 빨간 에러가 떠요NullReferenceException: Object reference not set to an instance of an object.
왜?C#에서 new를 안 하고 변수만 만든 채 썼어요. 쪽지에 아무 주소도 없는 상태예요. 유니티에서 가장 많이 보는 에러예요.
어떻게?쓰기 전에 new로 만들었는지, 유니티라면 인스펙터에 연결했는지 확인해요.
malloc 줄에서 변환할 수 없다고 나와요error C2440: '초기화 중': 'void *'에서 'int *'(으)로 변환할 수 없습니다.
왜?파일이 .cpp라서 C++ 규칙을 따라요. malloc이 돌려주는 void *(아무 주소)를 그냥 넣을 수 없어요.
어떻게?앞에 (int *)처럼 받을 포인터 자료형을 붙여요.
malloc을 모른다고 나와요.c: warning C4013: 'malloc'이(가) 정의되지 않았습니다. · .cpp: error C3861: 'malloc': 식별자를 찾을 수 없습니다.
왜?#include <stdlib.h>를 빼먹었어요.
어떻게?맨 위에 추가해요.
초록 물결 경고가 생겨요C6011: NULL 포인터 'arr'을(를) 역참조하고 있습니다.
왜?malloc이 실패해서 NULL을 돌려줄 수도 있는데 확인 없이 썼어요.
어떻게?빌린 직후에 if (arr == NULL)로 확인해요.
free 할 때 프로그램이 멈추며 창이 떠요HEAP CORRUPTION DETECTED: after Normal block ... CRT detected that the application wrote to memory after end of heap buffer.
왜?빌린 것보다 많은 칸에 썼어요. 보통 malloc(n)처럼 sizeof를 빼먹었거나, 반복이 n칸을 넘었을 때예요.
어떻게?malloc에 sizeof(자료형) * 칸 수가 있는지, 반복 조건이 i < n인지 확인해요.
free를 했는데 또 멈춰요Debug Assertion Failed! Expression: _CrtIsValidHeapPointer(block)
왜?같은 주소를 두 번 free 했거나, malloc으로 빌리지 않은 주소(보통 배열, 변수 주소)를 free 했어요.
어떻게?free 후에 p = NULL;을 넣어요. free(NULL)은 아무 일도 안 해서 안전해요.
반납한 뒤에 읽었더니 이상한 큰 음수가 나와요-572662307 (0xDDDDDDDD)
왜?Debug 모드에서 free된 칸은 0xDD로 채워져요. 반납한 메모리를 읽었다는 신호예요.
어떻게?free는 그 메모리를 다 쓴 다음, 맨 마지막에 해요.
