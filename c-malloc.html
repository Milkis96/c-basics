동적 할당필요할 때 필요한 만큼 메모리 빌리기

지금까지 변수와 배열은 코드를 쓸 때 크기가 정해졌어요. 동적 할당은 프로그램이 실행되는 중에 "칸 몇 개 빌려 주세요" 하고 메모리를 빌리고, 다 쓰면 반납하는 방법이에요.

1동적 할당이란?

실행 중에 메모리를 빌리고(malloc) 반납하는(free) 것이에요.동적 = 실행하면서 정해진다. 할당 = 나눠 준다.

도서관에서 책을 빌리는 것과 같아요. 빌리면 대출 번호(주소)를 받고, 그 번호로 책을 찾아 써요. 다 읽으면 반납해야 다른 사람이 빌릴 수 있어요. 반납을 안 하면 도서관 책이 점점 줄어들어요.

  • malloc: 바이트 수를 말하면 그만큼 빌려 주고, 시작 주소를 돌려줘요.
  • free: 빌린 주소를 주면 반납해요.
  • 빌린 메모리에는 이름이 없어요. 그래서 포인터로 주소를 들고 있어야 해요.

2왜 필요해?

보통 배열

int score[30]; 학생이 몇 명 올지 모르니 넉넉하게 잡아요. 5명이면 25칸이 낭비, 31명이면 모자라요.

동적 할당

학생 수를 먼저 입력받고, 딱 그만큼만 빌려요. 낭비도 없고 모자라지도 않아요.

크기를 실행 중에 정하기입력받은 숫자만큼 배열을 만들 수 있어요.
함수가 끝나도 남기기함수 안의 변수는 함수가 끝나면 사라지지만, 빌린 메모리는 free 전까지 남아요.
링크드 리스트의 재료노드를 하나씩 필요할 때 만들려면 동적 할당이 필요해요.

기본 순서

빌리기 → 확인 → 쓰기 → 반납

#include <stdlib.h>                         // malloc, free가 여기 있어요

int n;
scanf_s("%d", &n);

int *arr = (int *)malloc(sizeof(int) * n);   // ① 빌리기
if (arr == NULL) {                           // ② 못 빌렸는지 확인
    printf("메모리 부족\n");
    return 1;
}
for (int i = 0; i < n; i++) {
    arr[i] = 0;                              // ③ 배열처럼 쓰기
}
free(arr);                                   // ④ 반납
arr = NULL;                                  //    반납한 주소 지우기
  • sizeof를 꼭 곱해요. malloc은 칸 수가 아니라 바이트 수를 받아요. malloc(n)은 n바이트, int로는 n/4칸뿐이에요.
  • (int *)는 .cpp 파일에서 필요해요. 붙여 두면 .c, .cpp 둘 다 돼요.
  • 빌린 칸은 arr[i]로 배열처럼 써요. 포인터 2에서 배운 그대로예요.

규칙 하나: malloc 한 번에 free 한 번

빌린 횟수와 반납한 횟수가 같아야 해요. 덜 반납하면 메모리 누수, 두 번 반납하면 프로그램이 멈춰요.

5빌리고 반납하기

n을 3으로 입력했다고 해 볼게요. 힙의 5000번부터 3칸을 빌렸다고 할게요.

6문제 풀기

1번써 보기

double 10개를 담을 메모리를 빌려서 포인터 d에 담는 한 줄을 써 보세요.

정답 보기
double *d = (double *)malloc(sizeof(double) * 10);
많이 틀리는 답: malloc(10) (바이트 수인 걸 잊어서)
2번개수 세기

malloc(sizeof(int) * 4)는 몇 바이트를 빌릴까요?

정답 보기

16바이트예요. int 하나가 4바이트, 4칸이니까요.

3번틀린 것 찾기
int *p = (int *)malloc(sizeof(int) * 3);
p[0] = 1;
free(p);
printf("%d", p[0]);
정답 보기

마지막 줄: 이미 반납한 메모리를 읽었어요. 반납한 책을 다시 펼친 것과 같아요. free는 다 쓴 뒤에 하고, free 후에는 p = NULL;을 넣어 둬요.

4번틀린 것 찾기
void make(void) {
    int *p = (int *)malloc(sizeof(int) * 100);
    p[0] = 5;
}
// main에서 make()를 1000번 불러요
정답 보기

free가 없어요. 함수가 끝나면 포인터 p는 사라지지만 빌린 400바이트는 그대로 남아요. 주소를 잃어버렸으니 반납할 방법도 없어요. 1000번이면 약 400KB가 새요. 이게 메모리 누수예요.

많이 틀리는 답: "함수가 끝나면 자동으로 사라진다" (그건 스택 변수만)
5번도전

학생 수 n을 입력받고, 동적 할당으로 n칸 배열을 만들어 점수를 입력받은 뒤 평균을 출력하세요. 마지막에 반납까지 해요.

정답 보기
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n, sum = 0;
    printf("학생 수: ");
    scanf_s("%d", &n);

    int *score = (int *)malloc(sizeof(int) * n);
    if (score == NULL) return 1;

    for (int i = 0; i < n; i++) {
        printf("%d번 점수: ", i + 1);
        scanf_s("%d", &score[i]);
        sum += score[i];
    }
    printf("평균: %.1f\n", (double)sum / n);

    free(score);
    score = NULL;
    return 0;
}

7이럴 땐?

malloc 줄에서 변환할 수 없다고 나와요error C2440: '초기화 중': 'void *'에서 'int *'(으)로 변환할 수 없습니다.
왜?파일이 .cpp라서 C++ 규칙을 따라요. malloc이 돌려주는 void *(아무 주소)를 그냥 넣을 수 없어요.
어떻게?앞에 (int *)처럼 받을 포인터 자료형을 붙여요.
malloc을 모른다고 나와요.c: warning C4013: 'malloc'이(가) 정의되지 않았습니다. · .cpp: error C3861: 'malloc': 식별자를 찾을 수 없습니다.
왜?#include <stdlib.h>를 빼먹었어요.
어떻게?맨 위에 추가해요.
초록 물결 경고가 생겨요C6011: NULL 포인터 'arr'을(를) 역참조하고 있습니다.
왜?malloc이 실패해서 NULL을 돌려줄 수도 있는데 확인 없이 썼어요.
어떻게?빌린 직후에 if (arr == NULL)로 확인해요.
free 할 때 프로그램이 멈추며 창이 떠요HEAP CORRUPTION DETECTED: after Normal block ... CRT detected that the application wrote to memory after end of heap buffer.
왜?빌린 것보다 많은 칸에 썼어요. 보통 malloc(n)처럼 sizeof를 빼먹었거나, 반복이 n칸을 넘었을 때예요.
어떻게?malloc에 sizeof(자료형) * 칸 수가 있는지, 반복 조건이 i < n인지 확인해요.
free를 했는데 또 멈춰요Debug Assertion Failed! Expression: _CrtIsValidHeapPointer(block)
왜?같은 주소를 두 번 free 했거나, malloc으로 빌리지 않은 주소(보통 배열, 변수 주소)를 free 했어요.
어떻게?free 후에 p = NULL;을 넣어요. free(NULL)은 아무 일도 안 해서 안전해요.
반납한 뒤에 읽었더니 이상한 큰 음수가 나와요-572662307 (0xDDDDDDDD)
왜?Debug 모드에서 free된 칸은 0xDD로 채워져요. 반납한 메모리를 읽었다는 신호예요.
어떻게?free는 그 메모리를 다 쓴 다음, 맨 마지막에 해요.
