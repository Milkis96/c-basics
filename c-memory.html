1메모리란?

메모리는 값을 넣어 두는 번호 붙은 사물함이에요.사물함 한 칸은 1바이트이고, 칸마다 번호가 있어요. 이 번호를 주소라고 해요.

변수를 만들면 컴퓨터가 빈 사물함을 찾아 자료형 크기만큼 빌려줘요. int는 4칸, char는 1칸이에요. 우리는 이름(hp)으로 부르지만, 컴퓨터는 주소(1000번)로 찾아가요.

메모리는 프로그램이 실행되는 동안만 값을 기억해요. 프로그램을 끄면 사물함이 비워져요.

2왜 알아야 해?

scanf_s의 &"이 변수의 주소로 넣어 줘"라는 뜻이었어요.
배열값들이 사물함에 나란히 붙어 있어서 번호로 찾을 수 있어요.
포인터주소를 직접 다루는 도구예요. 메모리를 알아야 이해돼요.

3쓰는 법

sizeof

몇 칸 쓰는지 알아보기

printf("%zu\n", sizeof(int));     // 4
printf("%zu\n", sizeof(char));    // 1
printf("%zu\n", sizeof(double));  // 8

sizeof는 "몇 바이트야?"라고 묻는 연산자예요. 결과는 %zu로 출력해요.

&

사물함 번호(주소) 알아보기

int hp = 100;
printf("값: %d\n", hp);      // 100
printf("주소: %p\n", &hp);   // 예: 000000A1B2C3F7E4

변수 이름 앞에 &를 붙이면 그 변수의 주소가 나와요. 주소는 %p로 출력하고, 16진수(0~9, A~F)로 보여요. 실행할 때마다 다른 번호가 나와도 정상이에요.

4메모리의 구조

프로그램이 쓰는 메모리는 용도에 따라 네 구역으로 나뉘어요. 학교 건물로 생각해 볼게요.

코드 영역우리가 짠 프로그램 명령이 들어가요.학교의 시간표. 읽기만 하고 바꾸지 않아요.
데이터 영역함수 밖에서 만든 변수(전역 변수)가 들어가요.학교 게시판. 프로그램이 끝날 때까지 남아 있고 누구나 봐요.
스택 영역함수 안에서 만든 변수(지역 변수)가 들어가요.교실. 수업(함수)이 끝나면 정리돼요. 우리가 지금까지 만든 변수는 대부분 여기 있어요.
힙 영역필요할 때 직접 빌리고 돌려주는 공간이에요.빌려 쓰는 강당. malloc으로 빌리고 free로 돌려줘요. 2개월차에 배워요.

7이럴 땐?

  
주소가 이상한 긴 글자로 나와요000000A1B2C3F7E4

    
왜?고장이 아니에요. 주소는 16진수로 보여 줘요. 0~9 다음에 A~F를 써서 16개 숫자로 세는 방법이에요.

      
어떻게?그대로 두면 돼요. 주소끼리 차이를 보면 몇 칸 떨어져 있는지 알 수 있어요.

  
주소나 sizeof를 %d로 출력하니 경고가 나요warning C4477: 'printf' : 서식 문자열 '%d'에 'int' 형식의 인수가 필요하지만 ... 'int *'입니다.

    
왜?주소와 sizeof 결과는 int가 아니에요. 짝꿍 기호가 따로 있어요.

      
어떻게?주소는 %p, sizeof는 %zu를 써요.

  
아주 큰 배열을 만들었더니 프로그램이 바로 꺼져요Stack overflow (스택 오버플로)

    
왜?스택(교실)은 생각보다 작아요. 함수 안에서 int a[1000000];처럼 너무 큰 걸 만들면 넘쳐요.

      
어떻게?크기를 줄이거나, 2개월차에 배우는 힙(malloc)을 써요.
