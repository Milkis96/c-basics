1연산자란?

연산자는 값으로 계산하라고 시키는 기호예요.수학 시간의 +, - 와 비슷해요. 몇 개는 모양이나 뜻이 조금 달라요.

계산에 쓰는 값을 피연산자라고 해요. 7 + 3에서 7과 3이 피연산자, +가 연산자예요. 계산이 끝나면 결과 값 하나가 나와요.

2왜 필요해?

게임 속에서는 계속 계산이 일어나요.

몬스터를 잡으면
score = score + 10;
점수가 10 올라가요
공격을 받으면
hp = hp - damage;
체력이 깎여요
짝수 턴인지 알고 싶으면
turn % 2
0이면 짝수예요

3쓰는 법

연산자는 보통 값 두 개 사이에 써요. 계산한 결과는 =로 변수에 넣어 두어요.

sum결과 넣을 곳
=넣어라
a값
+연산자
b값
;끝!

컴퓨터는 오른쪽을 먼저 계산하고 그 결과를 왼쪽에 넣어요.

int a = 7;
int b = 3;
int sum = a + b;      // 10
printf("%d\n", a * b); // 21 (바로 출력해도 돼요)

4연산자 종류

계산하는 연산자

기호뜻예시결과
+더하기7 + 29
-빼기7 - 25
*곱하기 (× 대신 *)7 * 214
/나누기 (정수끼리면 몫만)7 / 23
%나머지7 % 21

/ 와 % 는 짝꿍이에요. 사탕 7개를 2명에게 나눠 주면 한 명당 3개(7 / 2), 남는 건 1개(7 % 2)예요. %는 정수에만 쓸 수 있어요.

줄여 쓰는 연산자

줄여 쓰기원래 모양뜻
hp -= 10;hp = hp - 10;hp에서 10 빼기
score += 5;score = score + 5;score에 5 더하기
gold *= 2;gold = gold * 2;gold 두 배
count++;count = count + 1;1 올리기
count--;count = count - 1;1 내리기

계산 순서

수학과 똑같이 * / %를 + -보다 먼저 계산해요. 먼저 하고 싶은 건 괄호로 묶어요.

int x = 2 + 3 * 4;    // 14 (3 * 4 먼저)
int y = (2 + 3) * 4;  // 20 (괄호 먼저)

6문제 풀기

  
머릿속으로 먼저 계산해 보고 정답을 열어 보세요.

  
1번결과 맞히기


printf("%d", 17 / 5);

    
정답 보기
3이에요. 정수끼리 나누면 몫만 남아요.
많이 틀리는 답: 3.4

  
2번결과 맞히기


printf("%d", 17 % 5);

    
정답 보기
2예요. 17을 5로 나누면 몫 3, 나머지 2예요.

  
3번결과 맞히기


printf("%d", 2 + 3 * 4);

    
정답 보기
14예요. 곱하기를 먼저 해요. 3 × 4 = 12, 12 + 2 = 14.
많이 틀리는 답: 20 (앞에서부터 계산해서)

  
4번결과 맞히기


int a = 5;
a += 3;
a *= 2;
printf("%d", a);

    
정답 보기
16이에요. 5 → 8 → 16 순서로 바뀌어요.

  
5번도전

    
정수 n이 짝수인지 알고 싶어요. 어떤 계산을 하면 될까요?

    
정답 보기
n % 2를 계산해요. 결과가 0이면 짝수, 1이면 홀수예요. 2로 나눠서 남는 게 없으면 짝수니까요. 조건문을 배우면 if (n % 2 == 0)으로 써요.






  
7이럴 땐?

  
나눗셈 결과에서 소수점이 사라져요7 / 2  →  3

    
왜?정수끼리 나누면 몫만 남아요.

      
어떻게?둘 중 하나를 소수로 바꿔요.
float r = 7.0f / 2;          // 3.5
float r2 = (float)a / b;     // 변수라면 (float)를 앞에

  
0으로 나눴더니 에러가 나거나 프로그램이 멈춰요error C2124: 0으로 나누거나 나머지 연산을 합니다.  ·  Integer division by zero

    
왜?어떤 수도 0으로 나눌 수 없어요. 수학에서도 안 되는 계산이에요.

      
어떻게?나누기 전에 나누는 수가 0이 아닌지 확인해요. (조건문에서 배워요)

  
float에 %를 쓰니 에러가 나요error C2296 / C2297: '%': 잘못된 피연산자 형식

    
왜?나머지 연산자 %는 정수끼리만 쓸 수 있어요.

      
어떻게?%를 쓸 값은 int로 만들어요.

  
평균을 구했는데 값이 이상해요int avg = a + b / 2;

    
왜?나누기를 먼저 해서 a + (b / 2)가 됐어요.

      
어떻게?더하기를 괄호로 묶어요. (a + b) / 2
