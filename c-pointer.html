포인터주소를 적어 둔 쪽지

값 대신 "값이 있는 곳의 주소"를 저장하는 변수예요. 보물 지도처럼, 쪽지에 적힌 주소를 따라가면 진짜 값을 만날 수 있어요.

1포인터란?

포인터는 주소를 담는 변수예요.보통 변수는 값을 담고, 포인터는 "그 값이 어디 있는지"를 담아요.

메모리 시간에 모든 변수는 번호(주소)가 붙은 사물함에 산다고 배웠어요. 포인터는 그 사물함 번호를 적어 둔 쪽지예요. 쪽지를 들고 가면 그 사물함을 열어 값을 보거나 바꿀 수 있어요.

2왜 필요해?

함수에서 원본 바꾸기함수에는 값의 복사본이 가요. 주소를 넘기면 원본을 직접 바꿀 수 있어요.
큰 데이터 빨리 넘기기큰 상자를 통째로 복사하는 대신 주소 쪽지만 건네요.
사실 이미 썼어요scanf_s("%d", &n)의 &n이 바로 주소예요.

따라가기

쪽지의 주소로 가서 값 보기, 바꾸기

int a = 10;
int *p = &a;       // p에 a의 주소를 적어요

printf("%d\n", *p);  // 10  : p가 가리키는 곳의 값
*p = 20;             // p가 가리키는 곳(a)에 20을 넣어요
printf("%d\n", a);   // 20  : a가 바뀌었어요!

변수 앞의 *는 "쪽지에 적힌 주소로 가라"는 뜻이에요. *p는 곧 a와 같아요.

4&와 *

포인터는 이 두 기호만 구분하면 돼요.

모양뜻예시읽는 법
&변수주소 알아내기&aa의 주소
int *p포인터 만들기 (선언할 때)int *p;int를 가리키는 쪽지 p
*포인터주소로 따라가기 (쓸 때)*p = 20;p가 가리키는 곳
포인터쪽지에 적힌 주소 자체p주소 1000

&와 *는 반대예요. &는 값에서 주소로, *는 주소에서 값으로 가요. 그래서 *&a는 다시 a예요.

알아 두기

  • 포인터도 자료형을 맞춰요. int 주소는 int *, float 주소는 float *에 담아요.
  • 아무 곳도 가리키지 않을 때는 NULL을 넣어 둬요. int *p = NULL;
  • 주소는 %p로 출력해요.

5쪽지 따라가기

a는 1000번 사물함에 있다고 해 볼게요. p에 주소를 적고, 그 주소로 가서 값을 바꿔 봐요.

5번도전

함수 안에서 원본 변수의 값을 두 배로 바꾸는 함수 twice를 포인터로 만들어 보세요.

정답 보기
void twice(int *x) {
    *x = *x * 2;     // 주소로 가서 원본을 바꿔요
}

int main(void) {
    int a = 5;
    twice(&a);       // 값이 아니라 주소를 넘겨요
    printf("%d\n", a);   // 10
    return 0;
}

함수 시간에는 a가 안 바뀌었죠? 주소를 넘기면 바뀌어요. 이게 Call by reference예요.

7이럴 땐?

초기화하지 않은 포인터를 썼어요warning C4700: 초기화되지 않은 'p' 지역 변수를 사용했습니다. · 액세스 위반
왜?쪽지에 아무 주소도 안 적었는데 따라가려고 했어요. 엉뚱한 사물함을 열게 돼요.
어떻게?만들 때 주소를 넣거나, 일단 NULL을 넣고 쓰기 전에 확인해요.
실행하자마자 "액세스 위반"으로 멈춰요예외 발생: 쓰기 액세스 위반입니다. p이(가) nullptr였습니다.
왜?NULL(아무 데도 아님)인 포인터를 따라가려고 했어요.
어떻게?쓰기 전에 확인해요. if (p != NULL) { *p = 20; }
포인터 자료형이 안 맞는다고 나와요.c: warning C4133: 'int *'과(와) 'float *' 사이의 형식이 호환되지 않습니다. · .cpp: error C2440
왜?int의 주소를 float 포인터에 담았어요.
어떻게?가리킬 변수의 자료형과 포인터 자료형을 맞춰요.
둘 다 포인터인 줄 알았는데 하나만 포인터예요int* a, b; // a만 포인터, b는 그냥 int
왜?*는 바로 옆 이름에만 붙어요.
어떻게?각각 붙이거나 한 줄에 하나씩 만들어요. int *a, *b;
