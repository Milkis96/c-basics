포인터 2쪽지를 들고 배열 위를 걸어 다니기

배열 이름은 사실 첫 칸의 주소예요. 그래서 포인터에 배열을 담고, 주소에 1을 더하면 다음 칸으로 한 걸음 옮겨 가요.

p10arr[0] · 1000
p20arr[1] · 1004
p30arr[2] · 1008

1배열과 포인터

배열 이름 = 첫 칸의 주소예요.arr 와 &arr[0] 은 같은 주소예요.

포인터 1에서는 쪽지가 변수 하나를 가리켰어요. 배열은 칸들이 바로 옆에 붙어서 줄지어 있어서, 쪽지에 적힌 주소를 조금씩 옮기면 칸을 차례로 방문할 수 있어요.

그래서 scanf_s로 문자열을 받을 때 name 앞에 &를 안 붙였던 거예요. name이 이미 주소거든요.

2왜 필요해?

함수에 배열 넘기기배열을 함수에 넘기면 사실 첫 칸의 주소가 가요. 그래서 함수 안에서 배열을 바꾸면 원본이 바뀌어요.
문자열 다루기const char *msg = "GAME OVER"; 처럼 문자열을 쪽지로 가리켜요.
링크드 리스트 준비"주소를 따라 다음 칸으로"가 링크드 리스트의 핵심이에요.

3쓰는 법

가리키기

포인터에 배열 담기

int arr[3] = { 10, 20, 30 };
int *p = arr;          // &arr[0]과 같아요. & 없이 이름만

printf("%d\n", *p);       // 10
printf("%d\n", *(p + 1)); // 20 : 한 칸 옆
printf("%d\n", p[2]);     // 30 : 포인터도 [ ]를 쓸 수 있어요
이렇게 써도이것과 같아요뜻
arr&arr[0]첫 칸의 주소
p + i&p[i]i칸 옆의 주소
*(p + i)p[i]i칸 옆의 값

4주소 더하기

p + 1 은 "주소 + 1"이 아니라 "한 칸 옆"이에요

int는 4바이트라서 int 포인터에 1을 더하면 주소가 4 늘어요. 자료형 크기만큼 알아서 뛰어요.

포인터 자료형한 칸 크기p가 1000일 때 p + 1
char *1바이트1001
int *4바이트1004
double *8바이트1008

p++ 와 arr++

  • p++: 쪽지에 적힌 주소를 한 칸 옆으로 고쳐 적어요. 가능해요.
  • arr++: 배열 이름은 자리가 정해진 주소라서 옮길 수 없어요. 에러예요.

함수에 배열 넘기기

void fill(int *a, int n) {      // int a[] 라고 써도 같아요
    for (int i = 0; i < n; i++) a[i] = 0;
}
int main(void) {
    int arr[5] = { 1, 2, 3, 4, 5 };
    fill(arr, 5);                 // 첫 칸 주소 + 칸 수를 넘겨요
    // arr은 이제 0 0 0 0 0
}

함수는 주소만 받아서 배열이 몇 칸인지 몰라요. 그래서 칸 수 n을 같이 넘겨요.

5걸어 보기

arr이 1000번부터 있다고 해 볼게요. p를 한 칸씩 옮기면서 값을 바꿔 봐요.

6문제 풀기

1번결과 맞히기
int arr[4] = { 3, 6, 9, 12 };
int *p = arr;
printf("%d", *(p + 2));
정답 보기

9예요. p + 2는 2칸 옆, 즉 arr[2]예요.

많이 틀리는 답: 6 (1번부터 센다고 생각해서)
2번결과 맞히기
int arr[3] = { 1, 5, 3 };
int *p = arr;
printf("%d", *p + 1);
정답 보기

2예요. *p + 1은 "p의 값(1)에 1 더하기"예요. "한 칸 옆의 값"은 *(p + 1)로 괄호가 필요해요.

많이 틀리는 답: 5 (한 칸 옆의 값이라고 생각해서)
3번주소 계산

double *d가 2000번을 가리켜요. d + 3은 몇 번일까요?

정답 보기

2024예요. double은 8바이트라서 3칸이면 24 늘어요.

많이 틀리는 답: 2003
4번틀린 것 찾기
int arr[3] = { 1, 2, 3 };
int *p = &arr;
arr++;
정답 보기

2번째 줄: arr이 이미 주소예요. int *p = arr; (&arr은 "배열 통째의 주소"라 자료형이 달라요.)
3번째 줄: 배열 이름은 옮길 수 없어요. 포인터 p를 옮겨요. p++;

5번도전

포인터만 써서([ ] 없이) 배열의 합을 구하는 함수 int sum(int *a, int n)을 만들어 보세요.

정답 보기
int sum(int *a, int n) {
    int total = 0;
    for (int i = 0; i < n; i++) {
        total += *(a + i);
    }
    return total;
}

*a를 더하고 a++로 한 칸씩 옮기는 방법도 맞아요.

7이럴 땐?

arr++ 를 썼더니 에러가 나요error C2105: '++'에 l-value가 필요합니다.
왜?배열 이름은 고정된 주소라 바꿀 수 없어요.
어떻게?포인터를 하나 만들어 그걸 옮겨요. int *p = arr; p++;
함수 안에서 sizeof로 배열 크기를 구했더니 이상해요sizeof(a) / sizeof(a[0]) → 2 (x64) 또는 1 (x86)
왜?함수에 넘어간 배열은 포인터예요. sizeof(a)는 포인터 크기(8 또는 4바이트)예요.
어떻게?칸 수는 main에서 구해서 매개변수로 같이 넘겨요.
이상한 값이 나오거나 실행 끝에 오류 창이 떠요Run-Time Check Failure #2 - Stack around the variable 'arr' was corrupted.
왜?포인터를 너무 멀리 옮겨서 배열 밖을 읽거나 썼어요. p + 3은 3칸 배열의 바깥이에요.
어떻게?반복 조건을 i < n으로, 포인터는 0 ~ n-1칸 안에서만 움직여요. 디버거 조사식에 p - arr을 넣으면 몇 번 칸인지 보여요.
포인터로 가리킨 문자열을 바꾸려니 멈춰요예외 발생: 쓰기 액세스 위반
왜?char *s = "Hi";의 "Hi"는 읽기 전용 메모리에 있어요. s[0] = 'h';는 금지예요.
어떻게?바꿀 문자열은 배열로 만들어요. char s[] = "Hi"; 읽기만 할 거면 const char *로 적어요.

에러 번호와 문구는 Visual Studio 기준이에요. 파일 종류(.c/.cpp)와 버전에 따라 조금 다를 수 있어요.
