랜덤컴퓨터가 주사위 굴리기

게임이 매번 똑같으면 재미없죠. 적이 나오는 위치, 가위바위보에서 컴퓨터의 선택처럼 예측할 수 없는 수가 필요할 때 랜덤을 써요.

1랜덤이란?

랜덤은 미리 알 수 없는 수를 뽑는 거예요.컴퓨터의 주사위예요. rand() 함수가 주사위를 굴려 줘요.

사실 컴퓨터는 진짜 주사위를 굴리지 못해요. 시작 숫자(씨앗, seed)로 복잡한 계산을 해서 랜덤처럼 보이는 수를 차례로 만들어요. 그래서 씨앗이 같으면 나오는 순서도 똑같아요.

2왜 필요해?

가위바위보컴퓨터가 무엇을 낼지 몰라야 해요
아이템 뽑기어떤 아이템이 나올지 모르게
적 등장 위치매번 다른 곳에서 나오게

3쓰는 법

#include <stdio.h>
#include <stdlib.h>   // rand, srand
#include <time.h>     // time

int main(void) {
    srand((unsigned)time(NULL));   // ① 씨앗 뿌리기: 프로그램 시작할 때 딱 한 번
    int dice = rand() % 6 + 1;     // ② 1~6 사이 수 뽑기
    printf("주사위: %d\n", dice);
    return 0;
}
rand()랜덤 수 하나 뽑기0부터 32767 사이의 수가 나와요
srand(씨앗)씨앗 정하기씨앗이 다르면 나오는 순서가 달라져요
time(NULL)지금 시각(초)실행할 때마다 다르니 씨앗으로 딱 좋아요

4범위 정하기

rand()는 너무 큰 수가 나와요. 원하는 범위로 줄일 때 연산자 시간에 배운 나머지 %를 써요.

코드나올 수 있는 수왜?
rand() % 60 ~ 56으로 나눈 나머지는 0부터 5까지
rand() % 6 + 11 ~ 60~5에 1을 더해서 주사위 모양으로
rand() % 30, 1, 2가위, 바위, 보 세 가지
rand() % 11 + 1010 ~ 200~10에 10을 더해서
공식: rand() % (가장 큰 수 - 가장 작은 수 + 1) + 가장 작은 수10~20이면 rand() % (20 - 10 + 1) + 10 = rand() % 11 + 10

6문제 풀기

  
1번써 보기
1부터 6까지 주사위 수를 뽑아 변수 d에 넣어 보세요.

    
정답 보기
int d = rand() % 6 + 1;

  
2번골라 보기
rand() % 3에서 나올 수 있는 수를 모두 써 보세요.

    
정답 보기
0, 1, 2예요. 3으로 나눈 나머지는 3이 될 수 없어요.
많이 틀리는 답: 1, 2, 3

  
3번써 보기
10부터 20까지(20 포함) 랜덤 수를 뽑아 보세요.

    
정답 보기
int n = rand() % 11 + 10;
20 - 10 + 1 = 11가지예요.

  
4번생각하기
srand 없이 rand()만 썼더니, 실행할 때마다 똑같은 수가 나와요. 왜 그럴까요?

    
정답 보기
씨앗을 안 뿌리면 항상 같은 씨앗(1)으로 시작해요. 씨앗이 같으면 계산 순서도 같아서 결과가 똑같아요. 프로그램 시작할 때 srand((unsigned)time(NULL));을 한 번 써요.

  
5번도전
컴퓨터가 가위, 바위, 보 중 하나를 랜덤으로 내고 화면에 보여 주게 해 보세요.

    
정답 보기
srand((unsigned)time(NULL));
int com = rand() % 3;   // 0: 가위, 1: 바위, 2: 보
if (com == 0) {
    printf("컴퓨터: 가위\n");
} else if (com == 1) {
    printf("컴퓨터: 바위\n");
} else {
    printf("컴퓨터: 보\n");
}
이게 4주차 가위바위보 게임의 시작이에요.






  
7이럴 땐?

  
실행할 때마다 같은 수가 나와요41, 18467, 6334, ... (매번 똑같음)

    
왜?srand를 안 썼어요.

      
어떻게?main 시작 부분에 srand((unsigned)time(NULL));을 한 번 써요.

  
반복문 안에서 뽑았더니 같은 수만 계속 나와요for (...) { srand(time(NULL)); n = rand() % 6 + 1; }

    
왜?srand를 반복문 안에 넣었어요. time은 1초마다 바뀌어서, 1초 안에 같은 씨앗을 계속 다시 뿌리게 돼요.

      
어떻게?srand는 프로그램 시작할 때 딱 한 번만. 반복문 밖으로 빼요.

  
time을 찾을 수 없다고 나와요error C3861: 'time': 식별자를 찾을 수 없습니다.  ·  .c: warning C4013

    
왜?time 함수가 든 도구 상자를 안 가져왔어요.

      
어떻게?맨 위에 #include <time.h>를 넣어요. rand, srand는 <stdlib.h>예요.

  
데이터가 손실될 수 있다는 경고가 나요warning C4244: '인수': 'time_t'에서 'unsigned int'(으)로 변환하면서 데이터가 손실될 수 있습니다.

    
왜?time의 결과는 srand가 받는 자료형보다 커요.

      
어떻게?앞에 (unsigned)를 붙여 "이 종류로 바꿔 줘"라고 알려 줘요. 씨앗으로 쓰기에는 문제없어요.

  
주사위에서 0이 나와요rand() % 6  →  0 ~ 5

    
왜?나머지는 0부터 시작해요.

      
어떻게?+1을 붙여요. rand() % 6 + 1
