문자열글자들을 한 줄로 세운 기차, 끝에는 멈춤 표시

C에는 "글자 여러 개"를 담는 자료형이 따로 없어요. 그래서 char 배열에 글자를 한 칸씩 넣고, 맨 끝에 "여기서 끝!" 표시 '\0'를 붙여요. 이게 문자열이에요.

1문자열이란?

문자열은 '\0'으로 끝나는 char 배열이에요.글자 하나는 char, 글자 여러 개는 char 배열 + 끝 표시.

"Kim"은 글자 3개지만 칸은 4개가 필요해요. 마지막 칸에 '\0'(널 문자, 숫자로는 0)이 들어가요. printf는 이 표시를 만날 때까지 글자를 찍어요. 표시가 없으면 어디서 멈춰야 할지 몰라요.

모양뜻칸 수
'A'글자 하나 (char)1
"A"문자열: 'A' + '\0'2
"Kim"'K' 'i' 'm' '\0'4

2왜 필요해?

이름 저장플레이어 이름, 캐릭터 이름은 글자 여러 개예요.
메시지 출력"GAME OVER", "승리!" 같은 문장을 다뤄요.
입력 비교"가위"를 입력했는지 확인하려면 문자열끼리 비교해야 해요.

3쓰는 법

만들기

문자열 변수 선언 + 초기화

char글자 칸
name이름
[20]칸 20개 (글자 19개 + '\0')
= "Kim"넣어라
;끝!
입출력

scanf_s로 받고 printf로 찍기

char name[20];

printf("이름: ");
scanf_s("%s", name, (unsigned)sizeof(name));   // & 없음! 크기는 꼭
printf("안녕, %s!\n", name);
  • 문자열은 %s로 입출력해요.
  • 배열 이름 자체가 주소라서 &를 붙이지 않아요.
  • scanf_s는 칸 수를 꼭 같이 넘겨요. 넘치는 입력을 막아 줘요.
  • %s는 띄어쓰기에서 멈춰요. "Kim Min"을 넣으면 "Kim"만 들어가요.

문자열에는 = 로 넣을 수 없어요

char name[20];
name = "Lee";               // 에러! 배열에는 대입이 안 돼요
strcpy_s(name, sizeof(name), "Lee");   // 이렇게 복사해요

만들 때(초기화)는 = "Kim"이 되지만, 나중에 바꿀 때는 복사 함수를 써야 해요.

4문자열 함수

맨 위에 #include <string.h>를 써야 해요. Visual Studio에서는 이름 끝에 _s가 붙은 안전한 버전을 써요.

하고 싶은 일함수예시결과
글자 수 세기strlenstrlen("Kim")3 ('\0'은 안 셈)
복사하기strcpy_sstrcpy_s(a, sizeof(a), "Hi")a가 "Hi"
뒤에 붙이기strcat_sstrcat_s(a, sizeof(a), "!")a가 "Hi!"
같은지 비교strcmpstrcmp(a, "Hi!")같으면 0

strcmp는 같으면 0이에요

if (strcmp(input, "가위") == 0) {   // 같을 때
    printf("가위를 냈어요\n");
}

사전 순서로 앞이면 음수, 뒤면 양수, 같으면 0이에요. "같으면 1"이라고 착각하기 쉬워요.

6문제 풀기

1번개수 세기

"Hello"를 담으려면 char 배열이 최소 몇 칸 필요할까요?

정답 보기

6칸이에요. 글자 5개 + '\0' 1개.

많이 틀리는 답: 5칸 ('\0'을 빼먹어서)
2번결과 맞히기
char s[10] = "Game";
printf("%d", (int)strlen(s));
정답 보기

4예요. strlen은 '\0' 앞까지 글자만 세요. 배열 칸 수(10)와 달라요.

많이 틀리는 답: 10 또는 5
3번결과 맞히기
char s[10] = "Hello";
s[2] = '\0';
printf("%s", s);
정답 보기

He예요. printf는 '\0'을 만나면 멈춰요. 뒤의 "lo"는 칸에 남아 있지만 출력되지 않아요.

4번틀린 것 찾기
char a[10];
a = "Hi";
if (a == "Hi") printf("same");
정답 보기

2번째 줄: 배열에는 =로 넣을 수 없어요. strcpy_s(a, sizeof(a), "Hi");
3번째 줄: ==는 글자가 아니라 주소를 비교해요. strcmp(a, "Hi") == 0으로 써요.

5번도전

이름을 입력받아 "가위바위보 게임에 온 걸 환영해, ○○!"를 출력하고, 이름이 "admin"이면 "관리자 모드"를 추가로 출력해 보세요.

정답 보기
#include <stdio.h>
#include <string.h>

int main(void) {
    char name[20];
    printf("이름: ");
    scanf_s("%s", name, (unsigned)sizeof(name));
    printf("가위바위보 게임에 온 걸 환영해, %s!\n", name);
    if (strcmp(name, "admin") == 0) {
        printf("관리자 모드\n");
    }
    return 0;
}

7이럴 땐?

strcpy, strcat를 쓰면 빌드가 안 돼요error C4996: 'strcpy': This function or variable may be unsafe. Consider using strcpy_s instead.
왜?Visual Studio는 칸 수를 확인하지 않는 옛날 함수를 막아요.
어떻게?strcpy_s(a, sizeof(a), "Hi")처럼 _s 버전에 칸 수를 넘겨요.
scanf_s로 문자열을 받았는데 프로그램이 멈추거나 아무것도 안 들어가요warning C4473: 'scanf_s': 서식 문자열에 전달된 인수가 부족합니다.
왜?%s에 칸 수를 안 넘겼어요. scanf_s는 크기를 꼭 받아야 해요.
어떻게?scanf_s("%s", name, (unsigned)sizeof(name));
출력하면 뒤에 이상한 글자(한자 같은 것)가 줄줄이 나와요Kim儆儆儆儆...
왜?'\0'이 없어서 printf가 멈출 곳을 못 찾고 옆 메모리까지 읽었어요. 칸을 한 글자씩 채우거나 칸 수를 딱 맞게 잡았을 때 잘 생겨요.
어떻게?칸을 글자 수 + 1 이상으로 잡고, 직접 채웠다면 끝에 '\0'을 넣어요.
실행 중에 "Buffer is too small" 창이 떠요Debug Assertion Failed! Expression: (L"Buffer is too small" && 0)
왜?strcpy_s / strcat_s로 넣으려는 글자가 배열 칸보다 많아요.
어떻게?배열 칸을 넉넉하게 잡아요. 붙이기는 원래 글자 + 붙일 글자 + 1칸이 필요해요.
같은 글자를 입력했는데 if가 거짓이에요if (input == "가위") // 항상 거짓
왜?==는 두 문자열이 놓인 주소를 비교해요. 글자가 같아도 사는 곳이 달라요.
어떻게?strcmp(input, "가위") == 0
