구조체여러 값을 묶어 나만의 자료형 만들기

게임 캐릭터에는 체력, 레벨, 속도가 함께 있어요. 따로따로 변수로 두지 않고, 하나의 "캐릭터 카드"로 묶을 수 있어요.

1구조체란?

구조체는 여러 값을 하나로 묶은 나만의 자료형이에요.int, float처럼 이미 있는 자료형 말고, "Player"라는 새 자료형을 직접 만드는 거예요.

구조체 안에 든 각각의 값을 멤버라고 해요. Player 카드의 hp, level, speed가 멤버예요. 배열은 같은 종류만 묶지만, 구조체는 다른 종류도 함께 묶을 수 있어요.

2왜 필요해?

따로따로 변수로
int p1Hp = 100, p1Level = 1;
int p2Hp = 80,  p2Level = 3;
int p3Hp = 120, p3Level = 2;
// 캐릭터가 늘면 끝없이...
구조체로
struct Player p1 = {100, 1};
struct Player p2 = {80, 3};
struct Player p3 = {120, 2};
// 카드 한 장 = 캐릭터 하나

관련 있는 값을 묶어 두면 실수가 줄고, 함수에 넘길 때도 카드 한 장만 건네면 돼요.

3쓰는 법

① 설계

카드 모양 정하기 (정의)

struct Player {
    int hp;
    int level;
    float speed;
};   // 끝에 세미콜론 꼭!

아직 카드는 없고 "Player 카드는 이렇게 생겼다"는 설계도만 만든 거예요. 보통 main 위에 써요.

② 만들기

설계도로 카드 만들기 (선언 + 초기화)

struct Player p1 = {100, 1, 2.5f};   // 설계도 순서대로 hp, level, speed
struct Player p2;                    // 일단 만들고
p2.hp = 80;                          // 나중에 하나씩 넣기
p2.level = 3;
p2.speed = 1.5f;
③ 사용

점(.)으로 멤버 꺼내기

printf("%d\n", p1.hp);   // 100
p1.hp -= 30;              // 70
p1.level++;               // 2

p1.hp는 "p1 카드의 hp 칸"이라고 읽어요. 멤버 하나하나는 보통 변수처럼 쓰면 돼요.

4더 써 보기

typedef

struct 안 쓰고 짧게 부르기

typedef struct {
    int hp;
    int level;
} Player;

Player p1 = {100, 1};   // struct 없이 Player만

C에서는 매번 struct Player라고 써야 해서 길어요. typedef로 별명을 붙이면 짧게 쓸 수 있어요.

배열

카드 여러 장 묶기

Player team[3] = { {100, 1}, {80, 3}, {120, 2} };
for (int i = 0; i < 3; i++) {
    printf("%d번 캐릭터 hp: %d\n", i, team[i].hp);
}
포인터

카드 주소로 멤버 꺼내기: ->

Player p1 = {100, 1};
Player *ptr = &p1;
ptr->hp = 50;        // (*ptr).hp = 50; 과 같아요
printf("%d\n", p1.hp);   // 50

카드를 직접 들고 있으면 점(.), 카드 주소(포인터)를 들고 있으면 화살표(->)를 써요.

7이럴 땐?

구조체 아래 줄에서 엉뚱한 구문 오류가 나요error C2143: 구문 오류 ... (구조체 정의 바로 다음 줄)
왜?구조체 정의 끝 } 뒤에 세미콜론이 없어요.
어떻게?};로 끝내요. 함수의 }와 달리 구조체는 세미콜론이 필요해요.
멤버가 아니라는 에러가 나요error C2039: 'hpp': 'Player'의 멤버가 아닙니다.
왜?멤버 이름 철자가 틀렸어요.
어떻게?설계도에 적은 이름 그대로 써요. 대소문자도 같아야 해요.
.c 파일에서 Player를 모른다고 나와요error C2065: 'Player': 선언되지 않은 식별자입니다.
왜?C(.c)에서는 typedef 없이 만든 구조체를 쓸 때 앞에 struct를 꼭 붙여야 해요. (.cpp에서는 없어도 돼서 더 헷갈려요.)
어떻게?struct Player p1;로 쓰거나 typedef로 별명을 만들어요.
포인터에 점(.)을 썼더니 에러가 나요error C2231: '.hp': 왼쪽 피연산자가 'struct'을(를) 가리킵니다. '->'를 사용하세요.
왜?포인터는 카드 자체가 아니라 카드 주소라서 점을 쓸 수 없어요.
어떻게?포인터일 때는 ptr->hp를 써요.
