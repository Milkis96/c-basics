변수값에 이름 짓기

숫자나 글자에 이름을 붙여 두면, 나중에 이름만 불러도 그 값을 꺼낼 수 있어요.

100 에 이름을 붙이면
hp100

1변수란?

변수는 값에 이름을 지어 주는 거예요.우리 반 친구에게 이름이 있는 것처럼, 프로그램 속 값에도 이름을 붙여 줘요.

게임 캐릭터의 체력이 100이라고 해 볼게요. 그냥 100이라고만 쓰면 이게 체력인지 점수인지 알 수 없어요. 그래서 hp(체력)라는 이름을 붙여 줘요.

hp100체력
score0점수
grade'A'등급 (글자도 돼요)

변수의 변은 "바뀐다"는 뜻이에요. 이름은 그대로 두고, 안에 든 값은 바꿀 수 있어요. 캐릭터가 공격을 받으면 hp가 100에서 70으로 바뀌는 것처럼요.

2왜 필요해?

이름이 없으면 부를 수가 없어요. 교실에서 친구를 부를 때를 생각해 보세요.

이름 없이 부르면
야, 저기 저 애 좀 불러 줘.
누구를 말하는지 몰라요.
이름으로 부르면
민준아!
딱 한 명이 대답해요.

컴퓨터도 똑같아요. 값에 이름을 붙여 두면 기억해 두었다가 필요할 때 정확하게 꺼낼 수 있어요.

int candy = 300;   // 사탕 한 개 가격
int count = 5;     // 사탕 개수
printf("%d", candy * count);   // 1500
// 사탕 가격이 바뀌면? 첫 줄만 고치면 끝!

3이름 짓는 법

변수를 만드는 데는 두 가지 일이 있어요. 이름표를 만드는 일(선언)과 처음으로 값을 넣는 일(초기화)이에요. 두 가지를 따로 할 수도 있고, 한 번에 할 수도 있어요.

선언

이름표만 먼저 만들기

문법자료형 이름;
int hp;
hp?

컴퓨터에게 "정수를 담을 hp라는 이름을 만들어 줘"라고 알려 주는 거예요. 이름표는 생겼지만 아직 값은 넣지 않았어요. 안에 무엇이 들어 있는지 알 수 없으니 바로 쓰면 안 돼요. (7번의 "이상하게 큰 숫자"가 이것 때문이에요.)

초기화

처음으로 값 넣기

문법이름 = 값;
int hp;      // 선언: 이름표 만들기
hp = 100;    // 초기화: 처음으로 100 넣기
hp100

이미 만들어 둔 이름표에 처음으로 값을 넣어요. 이름표는 벌써 있으니까 앞에 int를 다시 쓰지 않아요. 또 쓰면 이름표를 하나 더 만들려는 거라서 "재정의" 에러가 나요.

선언과 따로 값을 넣는 것을 정확한 용어로는 대입이라고 해요. 처음 넣는 값이라서 수업에서는 초기화라고도 불러요.

선언 + 초기화

이름표 만들면서 바로 값 넣기

문법자료형 이름 = 값;
int값의 종류
hp이름
=넣어라
100값
;끝!

소리 내어 읽으면 "정수 hp를 만들고 100을 넣어라. 끝!"이에요. 위의 두 줄을 한 줄로 줄인 거예요. 가장 많이 쓰는 방법이고, 값 넣는 걸 깜빡하는 실수도 막아 줘요.

한눈에 비교

하는 일문법예시앞에 int?
선언자료형 이름;int hp;붙여요
초기화 (나중에)이름 = 값;hp = 100;안 붙여요
선언 + 초기화자료형 이름 = 값;int hp = 100;붙여요

기억하기: int는 이름표를 새로 만들 때만 붙여요.

같은 종류라면 쉼표(,)로 한 줄에 여러 개를 만들 수도 있어요.

int x = 0, y = 0;   // x와 y를 만들고 둘 다 0 넣기

문장 끝의 ;(세미콜론)은 문장의 마침표 같은 거예요. 빼먹으면 컴퓨터가 화를 내요.

4값의 종류와 이름 약속

값의 종류 (자료형)

이름 앞에 쓰는 int는 "어떤 종류의 값인지"를 알려 줘요. 이걸 자료형이라고 해요.

int정수사과 개수, 점수, 나이
int age = 12;
float소수키, 몸무게, 속도
float height = 150.5f;
char글자 한 개등급, 반 이름
char grade = 'A';

소수 뒤의 f는 "이건 float이에요" 하고 붙이는 표시예요. 글자는 작은따옴표('A')로 감싸요.

이름 지을 때 약속

  1. 영어, 숫자, 밑줄(_)만 쓸 수 있어요. 한글은 안 돼요.
  2. 숫자로 시작하면 안 돼요.
  3. 띄어쓰기를 하면 안 돼요.
  4. int, if처럼 C언어가 이미 쓰고 있는 말은 못 써요.
  5. 대문자와 소문자는 다른 이름이에요. hp와 HP는 서로 다른 변수예요.
playerHp 좋아요
max_score 좋아요
item2 좋아요
2item 숫자로 시작
my hp 띄어쓰기
int 이미 쓰는 말

약속만 지키면 되는 건 아니에요. a, b보다 hp, score처럼 보기만 해도 무슨 값인지 알 수 있는 이름이 좋은 이름이에요.

5값 바꿔 보기

여기서 =는 수학 시간의 "같다"가 아니에요. "오른쪽 값을 왼쪽 이름에 넣어라"라는 뜻이에요. 버튼을 눌러 한 줄씩 실행해 보세요.

지금 있는 변수
화면에 나온 글자

hp = hp - damage;는 이렇게 읽어요. "지금 hp에서 damage만큼 빼고, 그 결과를 다시 hp에 넣어라."

6문제 풀기

먼저 스스로 풀어 보고 정답을 열어 보세요. 2번부터는 컴퓨터로 실행하지 말고 머릿속으로 결과를 맞혀 보세요.

1번써 보기

소수를 담는 float 변수 a를 만들고 5를 넣어 보세요.

정답 보기
float a = 5.0f;

float a = 5;라고 써도 정답이에요. 5가 알아서 5.0으로 바뀌어 들어가요.

2번결과 맞히기
int a = 3.7;
printf("%d", a);
정답 보기

3이 나와요. int는 정수만 담을 수 있어서 소수점 뒤를 그냥 버려요. 반올림해 주지 않아요.

많이 틀리는 답: 4 (반올림할 거라고 생각해서)
3번결과 맞히기
int a = 10;
a = a + 5;
a = a * 2;
printf("%d", a);
정답 보기

30이에요. a는 10 → 15 → 30 순서로 바뀌어요. 한 줄씩 차례대로 계산해요.

많이 틀리는 답: 20 (10 × 2만 계산해서)
4번틀린 것 찾기

변수 이름으로 쓸 수 없는 것을 모두 골라 보세요.

score   2player   player_2   my name   _count   float
정답 보기

2player(숫자로 시작), my name(띄어쓰기), float(C언어가 이미 쓰는 말)이에요. _count처럼 밑줄로 시작하는 건 괜찮아요.

5번결과 맞히기
int a = 5;
int b = a;
a = 10;
printf("%d", b);
정답 보기

5예요. b = a는 a의 값을 복사해서 b에 넣는 거예요. 친구 숙제를 복사해 왔는데, 나중에 친구가 자기 숙제를 고쳐도 내 복사본은 그대로인 것과 같아요.

많이 틀리는 답: 10 (b와 a가 이어져 있다고 생각해서)

7이럴 땐?

코드를 짜다 보면 꼭 한 번은 만나는 상황들이에요. 화면에 뜬 모습과 비슷한 걸 찾아보세요.

"선언되지 않은 식별자"라고 나와요error C2065: 'hp': 선언되지 않은 식별자입니다.
왜?아직 이름을 짓지 않은 변수를 불렀어요. 또는 이름 철자나 대소문자가 달라요.
어떻게?위쪽에 int hp가 있는지, hp를 HP로 쓰지 않았는지 확인해요.
이상하게 큰 숫자가 나와요-858993460 · C4700: 초기화되지 않은 'hp' 지역 변수를 사용했습니다.
왜?이름만 짓고 값을 안 넣은 채로 썼어요. 빈 상자가 아니라 쓰레기가 들어 있는 상자예요.
어떻게?이름을 지을 때 값도 같이 넣는 습관을 들여요.
int hp = 0;
소수점이 사라졌어요int a = 3.7; → 3
왜?정수만 담는 int에 소수를 넣었어요.
어떻게?소수가 필요하면 float를 써요.
"재정의"라고 나와요error C2086: 'int hp': 재정의
왜?같은 이름을 두 번 지었어요. 한 반에 똑같은 이름표를 두 개 만들 수는 없어요.
어떻게?값만 바꿀 때는 앞에 int를 빼요.
int hp = 100;
int hp = 50;  // 틀림: 이름을 또 지으려고 함
hp = 50;      // 맞음: 값만 바꿈
멀쩡한 줄에서 "구문 오류"가 나요error C2143: 구문 오류: ';'이(가) ... 앞에 없습니다.
왜?바로 윗줄 끝에 ;를 빼먹었어요. 컴퓨터는 다음 줄에 가서야 알아채요.
어떻게?에러가 난 줄과 그 윗줄 끝을 같이 봐요.
