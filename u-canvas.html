UI (Canvas)게임 화면 앞에 붙이는 유리판

HP, 점수, 버튼처럼 화면에 딱 붙어 있는 것을 UI라고 해요. 유니티에서 UI는 Canvas라는 판 위에 올려요. Canvas는 게임 화면 맨 앞에 붙은 투명한 유리창 같아요.

1Canvas란?

UI 요소를 올려 두는 판이에요. UI는 반드시 Canvas의 자식이어야 보여요.canvas = 그림 그리는 천, 화폭

Hierarchy에서 Canvas 아래에 들어간 Text, Image, Button만 화면에 그려져요. Canvas 밖으로 빼면 안 보여요.

Canvas 위의 UI는 Transform 대신 Rect Transform을 가져요. 위치뿐 아니라 가로·세로 크기와 화면 어디를 기준으로 붙을지(앵커)를 정해요.

2왜 따로 있어?

카메라와 상관없이 고정플레이어가 움직여 카메라가 따라가도 HP 글자는 화면 왼쪽 위에 그대로 있어야 해요.
해상도 맞추기PC, 태블릿, 휴대폰은 화면 크기가 달라요. Canvas Scaler와 앵커가 UI 크기와 자리를 맞춰 줘요.
클릭 처리같이 생기는 EventSystem이 버튼 클릭·터치를 받아 줘요.

3만드는 순서

  1. Hierarchy 우클릭 → UI → Text - TextMeshPro처음이면 TMP Importer 창이 떠요. Import TMP Essentials를 눌러요. (Unity 6에서는 메뉴 이름이 "UI (Canvas)"로 보일 수 있어요)
  2. Canvas와 EventSystem이 자동으로 생겨요Text는 Canvas의 자식으로 들어가 있어요.
  3. Canvas 선택 → Canvas Scaler → UI Scale Mode를 Scale With Screen Size로Reference Resolution은 1920 × 1080. 화면이 작아지면 UI도 같이 작아져요.
  4. Scene 창 위의 2D 버튼을 켜고, Canvas를 더블클릭Canvas가 화면 전체에 맞춰 보여요.
  5. Rect Transform의 앵커 프리셋(네모 아이콘)으로 기준 위치 정하기Alt를 누르고 고르면 위치까지 그 자리로 같이 옮겨져요.
  6. Game 창 위의 해상도 메뉴로 크기를 바꿔 보며 확인Free Aspect 대신 1920×1080, 세로 화면 등을 추가해서 봐요.
예제

HP 글자 바꾸기 + 버튼 연결

using UnityEngine;
using TMPro;                        // TextMeshPro를 쓰려면 꼭

public class UIManager : MonoBehaviour
{
    public TMP_Text hpText;          // Inspector에서 HP 글자 오브젝트를 끌어다 넣어요
    int hp = 100;

    void Start()
    {
        hpText.text = "HP: " + hp;
    }

    public void OnClickHeal()        // 버튼에 연결할 함수는 public
    {
        hp += 10;
        hpText.text = "HP: " + hp;
    }
}

버튼에 함수 연결하기

① 빈 오브젝트(예: UIManager)에 위 스크립트를 붙이고, hpText 칸에 Text 오브젝트를 끌어다 놓아요. ② Button을 선택해 Inspector의 On Click () 목록에서 +를 눌러요. ③ 빈 칸에 UIManager 오브젝트를 끌어다 놓고, 함수 메뉴에서 UIManager → OnClickHeal을 골라요.

같은 Canvas 안에서는 Hierarchy에서 아래쪽에 있을수록 앞에 그려져요. 버튼이 Panel에 가려지면 버튼을 Panel 아래로 끌어 내려요.

5앵커 실험

1920 × 1080 화면에서 오른쪽 위에 일시정지 버튼을 놓았어요. 앵커(기준점, 빨간 점)와 Canvas Scaler를 바꾼 뒤 화면 크기를 바꿔 보세요. 어떤 조합이 모든 화면에서 오른쪽 위를 지킬까요?

앵커

Canvas Scaler

화면 크기

일시정지

정답 조합은 앵커 오른쪽 위 + Scale With Screen Size예요. 앵커는 "어디를 기준으로 붙을지", Canvas Scaler는 "화면 크기에 맞춰 커지고 작아질지"를 정해요.

6문제 풀기

1번결과 맞히기

HP Text를 Hierarchy에서 Canvas 밖(맨 위 칸)으로 끌어냈어요. 게임 화면에서 HP 글자는?

정답 보기

안 보여요. UI는 Canvas의 자식일 때만 그려져요.

2번결과 맞히기

Canvas 안의 Hierarchy 순서가 Button, 그 아래 Panel이에요. Panel이 화면 전체를 덮어요. 버튼은?

정답 보기

Panel에 가려지고 클릭도 안 돼요. 아래쪽(Panel)이 앞에 그려지고, 클릭도 Panel이 먼저 받아요.

3번원인 찾기
void OnClickHeal()
{
    hp += 10;
}

Button의 On Click () 함수 목록에 OnClickHeal이 안 보여요. 왜일까요?

정답 보기

public이 빠졌어요. 안 쓰면 private이라 버튼이 못 봐요. public void OnClickHeal()로 고쳐요.

4번고쳐 보기
hpText.text = hp;

hp는 int예요. 에러가 나요. 고쳐 보세요.

정답 보기

.text에는 글자(string)만 들어가요.

hpText.text = "HP: " + hp;
// 또는 hpText.text = hp.ToString();
5번도전

휴대폰 세로 화면에서도 점수가 항상 화면 위 가운데에 있게 하려면 앵커와 Canvas Scaler를 어떻게 정할까요?

정답 보기

앵커는 위 가운데(top-center), Canvas Scaler는 Scale With Screen Size예요. 위 5번 실험에서 직접 확인해 보세요.

7이럴 땐?

한글이 네모(□□□)로 나와요HP □□□ / Console: The character with Unicode value 한 was not found in the [LiberationSans SDF] font asset or any potential fallbacks.
왜?TextMeshPro 기본 폰트(LiberationSans SDF)에 한글이 없어요.
어떻게?한글 폰트 파일(.ttf)을 프로젝트에 넣고 Window → TextMeshPro → Font Asset Creator에서 한글 폰트 에셋을 만들어 Text의 Font Asset 칸에 넣어요. 만드는 설정은 수업 때 같이 해요.
버튼을 눌러도 반응이 없어요 (에러 없음)On Click () 연결은 했는데 아무 일도 안 일어남
왜?① Hierarchy에 EventSystem이 없거나 ② 다른 UI(Panel, Image)가 버튼 위를 덮고 있거나 ③ On Click ()에 오브젝트만 넣고 함수를 안 골랐어요(No Function).
어떻게?EventSystem이 없으면 Hierarchy 우클릭 → UI → Event System. 덮고 있는 Image는 Inspector에서 Raycast Target 체크를 꺼요.
TMP_Text를 모른대요error CS0246: The type or namespace name 'TMP_Text' could not be found (are you missing a using directive or an assembly reference?)
왜?맨 위에 using TMPro;가 없어요.
어떻게?using TMPro;를 추가해요.
글자를 바꾸려니 칸이 비었대요UnassignedReferenceException: The variable hpText of UIManager has not been assigned.
왜?Inspector의 Hp Text 칸에 Text 오브젝트를 안 끌어다 놓았어요.
어떻게?Hierarchy의 Text 오브젝트를 그 칸으로 끌어다 놓아요. 칸에 안 들어가면 변수 자료형이 Text(옛날 UI)인지 확인하고 TMP_Text로 바꿔요.
화면 크기를 바꾸니 UI가 밀려나거나 사라져요1920×1080에선 괜찮았는데 휴대폰에선 화면 밖
왜?앵커가 가운데(기본값)이고 Canvas Scaler가 Constant Pixel Size예요.
어떻게?앵커를 붙고 싶은 모서리로, Canvas Scaler를 Scale With Screen Size로. 위 5번 실험 참고.
Scene 창에서 Canvas가 엄청 커요플레이어는 점처럼 작고 Canvas는 거대함
왜?정상이에요. Canvas는 1픽셀을 게임 세계 1칸으로 그려서 Scene 창에서는 커 보여요. Game 창에서는 화면에 딱 맞아요.
어떻게?UI 작업할 땐 2D 버튼을 켜고 Canvas를 더블클릭해서 봐요.
글자 박스는 있는데 글자가 안 보여요Text 오브젝트는 있음, 화면엔 빈칸
왜?글자 크기(Font Size)가 박스보다 커서 잘렸거나, 글자 색이 배경과 같아요.
어떻게?Rect Transform의 Width/Height를 늘리거나 Font Size를 줄여요. Auto Size를 켜면 박스에 맞춰져요.

메뉴 이름과 메시지는 Unity 6 기준이에요. 버전에 따라 조금 다를 수 있어요.
