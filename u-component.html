컴포넌트오브젝트에 붙이는 기능 부품

유니티의 게임 오브젝트는 처음엔 빈 상자예요. 여기에 "보이기", "떨어지기", "부딪히기" 같은 부품을 붙여서 원하는 물건으로 만들어요. 이 부품이 컴포넌트예요.

1컴포넌트란?

게임 오브젝트에 붙여서 기능을 주는 부품이에요.component = 구성 요소, 부품

Hierarchy에서 Create Empty로 만든 오브젝트에는 Transform(위치·회전·크기) 하나만 붙어 있어요. 화면에 보이지도, 움직이지도 않아요. Inspector의 Add Component로 부품을 붙일수록 할 수 있는 일이 늘어나요.

우리가 만든 C# 스크립트도 컴포넌트예요. : MonoBehaviour가 "이 클래스는 오브젝트에 붙일 수 있는 부품이에요"라는 표시예요.

C의 구조체와 비교하면

구조체는 변수들을 묶은 것이었어요. 컴포넌트는 변수 + 함수를 묶은 부품이고, 게임 오브젝트는 그 부품들을 끼우는 틀이에요.

2왜 부품으로 나눠?

필요한 것만 골라 붙여요벽은 보이고 부딪히기만 하면 돼요(SpriteRenderer + Collider). 떨어질 필요가 없으니 Rigidbody는 안 붙여요.
한 번 만든 부품을 계속 써요Rigidbody2D를 플레이어에도, 적에도, 상자에도 똑같이 붙여요. 물리 코드를 매번 짤 필요가 없어요.
기능별로 스크립트를 나눠요이동은 PlayerMove, 체력은 PlayerHp. 고칠 때 어디를 볼지 바로 알아요.

3코드에서 쓰기

예제

같은 오브젝트의 다른 부품 꺼내 쓰기

using UnityEngine;

public class Player : MonoBehaviour       // MonoBehaviour → 붙일 수 있는 부품
{
    public float speed = 5f;               // public → Inspector에 칸이 생겨요
    SpriteRenderer sr;

    void Awake()
    {
        sr = GetComponent<SpriteRenderer>(); // 내 오브젝트에 붙은 SpriteRenderer 찾기
    }

    void Start()
    {
        sr.color = Color.red;              // 꺼낸 부품의 값을 바꿔요
        transform.position = new Vector3(0, 2, 0);  // Transform은 바로 transform
    }
}
코드뜻
GetComponent<T>()내 오브젝트에 붙은 T 부품을 찾아 줘요. 없으면 null
AddComponent<T>()게임 중에 T 부품을 새로 붙여요
transform내 Transform. 모든 오브젝트에 있어서 GetComponent 없이 바로 써요
gameObject이 부품이 붙어 있는 오브젝트 자신
enabled = false이 부품만 끄기 (Inspector 체크 해제와 같아요)
Destroy(sr)부품 떼어 내기. Destroy(gameObject)는 오브젝트 통째로 삭제

4자주 쓰는 컴포넌트

컴포넌트하는 일없으면?
Transform위치 · 회전 · 크기없을 수 없어요 (항상 붙어 있음)
SpriteRenderer2D 그림을 보여 줘요화면에 안 보여요
Rigidbody2D중력, 힘, 속도로 움직여요안 떨어지고 그 자리에 있어요
BoxCollider2D · CircleCollider2D부딪히는 모양다른 것을 통과해요
AudioSource소리 재생소리가 안 나요
Animator애니메이션 재생그림이 안 움직여요
내 스크립트내가 정한 행동아무 행동도 안 해요

3D에서는 이름에 2D가 빠진 Rigidbody, BoxCollider, 그림은 MeshRenderer를 써요. 2D와 3D 부품은 서로 안 섞여요.

6문제 풀기

1번개념

Create Empty로 만든 빈 오브젝트에 처음부터 붙어 있는 컴포넌트는?

정답 보기

Transform 하나예요. 위치가 없는 오브젝트는 없어서 항상 붙어 있고, 뗄 수도 없어요.

2번원인 찾기

Transform, Rigidbody2D, BoxCollider2D가 붙은 오브젝트가 화면에 안 보여요. 무엇이 빠졌을까요?

정답 보기

SpriteRenderer예요. 그림을 그려 주는 부품이 없어서 물리로는 존재하지만 눈에 안 보여요.

3번원인 찾기

공(Rigidbody2D, CircleCollider2D)이 바닥을 그냥 뚫고 떨어져요. 바닥에는 SpriteRenderer만 있어요. 무엇을 붙여야 할까요?

정답 보기

바닥에 BoxCollider2D예요. 부딪히려면 양쪽 모두 Collider가 있어야 해요.

4번고쳐 보기
Rigidbody2D rb;

void Start()
{
    rb.gravityScale = 0;   // NullReferenceException!
}

오브젝트에 Rigidbody2D가 붙어 있는데도 에러가 나요. 왜일까요?

정답 보기

변수 rb만 만들고 부품을 찾아서 넣지 않았어요. C에서 포인터를 만들고 주소를 안 넣은 것과 같아요.

void Start()
{
    rb = GetComponent<Rigidbody2D>();
    rb.gravityScale = 0;
}
5번도전
public int hp = 100;

Inspector에서 Hp 칸을 50으로 바꾸고 Play를 눌렀어요. 게임이 시작하면 hp는?

정답 보기

50이에요. public 변수는 Inspector 값이 코드의 = 100보다 우선이에요. 코드만 고쳐서 값이 안 바뀐다면 Inspector를 확인해요.

많이 틀리는 답: 100

7이럴 땐?

부품을 쓰려는데 null이래요NullReferenceException: Object reference not set to an instance of an object
왜?변수에 부품을 넣지 않았어요. GetComponent를 안 했거나, 찾는 부품이 오브젝트에 없어요.
어떻게?Console의 에러를 두 번 클릭해 그 줄로 가요. 그 줄에서 쓰는 변수에 GetComponent로 값을 넣었는지 확인해요.
부품이 없대요MissingComponentException: There is no 'Rigidbody2D' attached to the "Player" game object, but a script is trying to access it.
왜?GetComponent는 했는데 오브젝트에 그 부품이 안 붙어 있어요.
어떻게?Inspector → Add Component로 Rigidbody2D를 붙여요. 스크립트 클래스 위에 [RequireComponent(typeof(Rigidbody2D))]를 쓰면 스크립트를 붙일 때 자동으로 같이 붙어요.
Inspector 칸을 안 채웠대요UnassignedReferenceException: The variable target of Player has not been assigned.
왜?public Transform target;처럼 public 칸을 만들어 놓고 Inspector에서 아무것도 끌어다 놓지 않았어요.
어떻게?Hierarchy에서 대상 오브젝트를 Inspector의 그 칸으로 끌어다 놓아요.
스크립트가 안 붙어요Can't add script component 'Player' because the script class cannot be found. Make sure that there are no compile errors and that the file name and class name match.
왜?파일 이름과 클래스 이름이 다르거나 컴파일 에러가 남아 있어요.
어떻게?Player.cs ↔ public class Player 이름을 맞추고 빨간 에러를 먼저 고쳐요.
둘 다 Collider가 있는데 통과해요 (에러 없음)BoxCollider + Rigidbody2D
왜?2D 부품(Rigidbody2D, BoxCollider2D)과 3D 부품(Rigidbody, BoxCollider)이 섞였어요. 2D와 3D 물리는 서로 모르는 사이예요.
어떻게?2D 게임이면 이름 끝에 2D가 붙은 부품으로 모두 맞춰요.
Play 중에 바꾼 값이 다 사라졌어요Play 종료 후 Inspector 값이 원래대로
왜?Play 모드에서 바꾼 값은 저장되지 않아요. 테스트용으로만 바뀌어요.
어떻게?마음에 드는 값은 적어 두었다가 Play를 끈 뒤 다시 넣어요. (Play 중엔 화면이 살짝 어둡게 보여요)

메시지는 Unity 6 기준이에요. 버전에 따라 문구가 조금 다를 수 있어요.
